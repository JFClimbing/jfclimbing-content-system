## 第 2 张：先搞懂保护器只有三大类

**大字**：
```
保护器只有三类
不是「牌子不同」，是「原理不同」
```

| 类别 | 代表 | 制动原理 |
|---|---|---|
| **管式** Tubular | ATC / Reverso / ATC-Guide | **手动**（靠你握住制动端） |
| **辅助制动** Assisted | 龟龟 GriGri / Revo | **凸轮辅助**（松手能锁住） |
| **8字环** Figure-8 | 8字环 | 手动（老式） |

**小字**：
```
原则：先看「哪一类」，再看「哪个牌子」
```

**画什么**：三个分类的图标 + 内部结构剖面（管式=弯曲槽道；辅助=凸轮；8字=环）

## 第 3 张：管式（ATC）—— 便宜、通用、全靠你

**大字**：
```
管式 / ATC
最便宜，也最考验人
```

**优点**：
```
✓ 便宜（¥200 左右）
✓ 轻
✓ 单绳 / 双绳都能用
✓ 能做双绳下降     ← 龟龟做不到
✓ 带「向导环」的款式上方保护能自锁
```

**缺点**：
```
✗ 没有自锁 —— 手一松就没了
✗ 对保护者的注意力要求最高
```

**画什么**：ATC 的穿绳示意 + 一个「手必须一直握住制动端」的高亮手势

---

## 第 4 张：辅助制动（龟龟）—— 容错高、贵、重

**大字**：
```
辅助制动 / 龟龟 GriGri
容错率高，但不是「自动」
```

**优点**：
```
✓ 凸轮机构，受力时会锁住 → 容错高
✓ 保护者省力（长时间保护不累）
✓ 适合岩馆顶绳 / 新手保护
```

**缺点**：
```
✗ 贵（¥700–950）
✗ 重（比 ATC 重一倍多）
✗ 单绳专用（不能双绳下降）    ← 户外多段要小心
✗ 对绳径敏感（太细的绳可能不锁）
```

**⚠️ 大字（红色，本集最重要的一句）**：
```
龟龟不是自动保护器
制动端一样不能松手
```

**画什么**：龟龟内部凸轮结构 + 一个「❌ 松手」的示意图

## 第 5 张：8字环 —— 现在还有人用，但……

**大字**：
```
8字环
不建议攀岩用，但不是没用
```

```
现在主要用在：
· 下降 / 绳降
· 救援

攀岩保护很少用它：
✗ 绳容易扭（麻花）
✗ 制动效果差
✗ 沉重
```

**大字结论**：
```
攀岩保护 → 不用 8 字
但如果你做绳降，它便宜好用
```

## 第 6 张：怎么选？按「你在哪攀」决定

**大字**：
```
选哪个？看你在哪攀
```

**三种场景 → 对应选择**：

| 你的主要场景 | 推荐 | 为什么 |
|---|---|---|
| **岩馆顶绳为主**（新手） | **龟龟** | 容错高，保护者不累，出错的代价小 |
| **户外运动攀 / 想学技术** | **ATC（带向导环）** | 便宜、通用、能双绳下降；向导环上方保护能自锁 |
| **两者都要** | **先买 ATC-Guide，再加一个龟龟** | 一个管式打底，一个辅助提升安全余量 |

**小字**：
```
⚠️ 如果你保护经验少、又只做岩馆顶绳 → 优先龟龟
   它的容错率能救你（和你的伙伴）
```

## 第 7 张：买之前一定要看的 3 个参数

**大字**：
```
买之前看这 3 个
```

```
① 适用绳径
   ATC       8.9 – 11 mm
   ATC-Guide 8.1 – 11 mm
   GriGri+   8.5 – 11 mm
   → 你的绳子直径必须在区间内，尤其龟龟

② 单绳 / 双绳
   ATC 系列：单双都能用
   龟龟：单绳专用
   → 你如果以后要爬多段，龟龟单独带不够

③ 有没有「向导环」
   有向导环 → 上方保护时可以自锁（做多段必备）
   → ATC-Guide / Reverso 才有
```

**画什么**：三个参数做成「查表」的视觉
