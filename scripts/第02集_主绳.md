## 第 2 张：先分清动力绳 vs 静力绳 ⚠️

**大字**：
```
第一步：分动力 / 静力
选错 = 要命
```

**分栏**：

| | 动力绳 DYNAMIC | 静力绳 STATIC |
|---|---|---|
| 特性 | **会拉伸**（吸收冲坠能量） | 几乎不拉伸 |
| 用途 | **攀岩** | 绳索作业 / 下降 / 救援 |
| 延展率 | 受力时明显伸长 | < 5% |

**大字结论（红色）**：
```
攀岩只买动力绳
用静力绳攀岩 = 冲坠力直接传到人身上
```

**画什么**：左边一条被拉长、中间有人坠落的示意；右边一条笔直的绳。
用**对比图**呈现（这是最容易记住的形式）。

## 第 3 张：动力绳分三类（UIAA 标准）

**大字**：
```
动力绳的三类
新手只需要看第一行
```

**表格**：

| 类型 | 直径 | 怎么用 | 新手 |
|---|---|---|---|
| **单绳** Single | 8.9–11 mm | 单股用，运动攀 / 顶绳 | ✅ **只买这个** |
| **半绳** Half | 7.8–9 mm | 双股**交替**挂 | ❌ 暂时不用 |
| **双子绳** Twin | 7.5–8.5 mm | 双股**并排**挂 | ❌ 暂时不用 |

**小字**：
```
半绳 / 双子绳是为传统攀、长距离路线设计的
室内 + 运动攀，单绳走天下
```

**画什么**：三根绳并排，单绳一根、半绳两根交替穿过快挂、双子绳两根并排穿过快挂。

## 第 4 张：直径怎么选

**大字**：
```
直径：粗的好抓，细的轻
新手别贪细
```

**左右对比**：

```
粗（10.2mm）          细（9.2mm）
✓ 好抓握              ✓ 轻、顺滑
✓ 耐磨、寿命长         ✗ 抓不住（尤其戴手套）
✓ 对保护技术宽容       ✗ 磨损快
✗ 重                  ✗ 对保护者技术要求高
```

**大字结论**：
```
新手建议：9.6 – 10.2 mm
```

**小字**：
```
很多人一开始买 9.2 的细绳，结果：
抓不住、磨得快、每次保护手都酸
```

**画什么**：两根绳横截面对比（粗/细）+ 一只手握绳的示意。

## 第 5 张：长度怎么选

**大字**：
```
长度：买之前先问你常去的场地
```

| 长度 | 适用 |
|---|---|
| 50 m | 部分岩馆 |
| **60 m** | **最通用**（多数岩馆 + 多数运动攀路线） |
| **70 m** | 很多现代路线 / 需要下降两次的路线 |
| 80 m | 特定长路线 |

**大字结论**：
```
不确定就买 60m
如果常去户外运动攀，问清楚路线需不需要 70m
```

**小字**：
```
⚠️ 买短了：到不了顶 / 下降不够
⚠️ 买长了：贵、重、还要多买一根绳包
```

## 第 6 张：结构 + 干绳处理（一句带过）

**大字**：
```
绳皮 + 绳芯
绳皮管耐磨，绳芯管强度
```

**要点**：
- **绳皮占比越高 → 越耐磨、寿命越长**（一般 30–40%）
- **中段标记**：正规绳会在中间做标记，方便判断绳长（下降时救命）
- **干绳处理（Dry）**：防水防冰，**室内攀岩不需要加钱买**

**大字结论**：
```
室内为主 → 不用买干绳
常去雪山 / 湿冷环境 → 值得加钱
```

新手最容易犯的 3 个错
