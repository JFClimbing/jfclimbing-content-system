# 小红书 A/B 测试：只换封面，重发「主绳 + 辅绳」

> **目的**：验证「小红书封面要用真实照片，不要用图解」这条假设
> **方法**：同一条内容，**只变封面**，其他不动
> **预期**：观看量明显提升（如果假设成立）

---

## 背景数据（为什么做这个测试）

「主绳+辅绳」09-16 发在小红书，T+2d：

| 指标 | 数值 | 诊断 |
|---|---:|---|
| 观看 | 220 | ❌ 只超过历史 13% |
| **分享率** | **1.82%** | ✅ 历史 top-2 档（中位 0.27%） |
| **收藏/点赞** | **70%** | ✅ 历史中位只有 31% |

**内容指标优秀 + 触达低 → 问题在封面，不在内容。**

依据：46 篇实测，小红书**每图字数与观看量秩相关 −0.636**；
观看前 3 名的封面 OCR **全空**（纯照片），后 3 名全是手绘信息图解。

# 方案 A（推荐）：直接编辑原帖换封面

## 为什么优先这个

**这是最干净的 A/B** —— 同一个帖子，**只有封面变了**。
其他变量（标题、正文、发布时间、账号状态）全部不变。

## 步骤

```
1. 打开小红书 App → 我的 → 找到「攀岩绳怎么选？ 主绳+辅绳 一篇讲透」
2. 点右上角「…」→ 看有没有「编辑」
   · 有 → 进入编辑 → 换封面 → 保存
   · 没有 → 走方案 B
```

> ⚠️ 小红书对已发布笔记的编辑有**次数限制**（通常 1 次），所以**先想好封面再动手**。

## 封面选哪张

**三个选项，按推荐度排：**

| 选项 | 怎么拍 | 为什么 |
|---|---|---|
| ⭐⭐ **两根绳平铺** | 主绳（Beal 蓝绳）+ 辅绳（红白菊绳）并排放在地上/桌上，自然光拍 | 跟你第 0 集那张装备平铺照同一风格，**已被验证是"照片感"** |
| ⭐⭐ **绳 + 装备组合** | 蓝绳盘好 + 快挂 + 主锁 摆一起 | 信息量大但**没有文字** |
| ⭐ **你和绳的合影** | 站在岩壁前 + 绳搭在肩上 | 有人 → 信任感更强，但需要拍 |

**硬性要求**：
- ❌ **不要加任何文字**
- ❌ 不要手绘、不要图解
- ✅ 真实拍摄、光线自然

## 换完之后看什么

**换完 24 小时后回来看：**

| 结果 | 结论 |
|---|---|
| 观看明显上涨（比如 +50% 以上） | ✅ **封面假设成立**，以后小红书一律用照片封面 |
| 观看几乎不动 | 封面不是主因，需要重新找变量（可能是账号权重/流量池问题） |

# 方案 B：如果编辑不了，就发一条新的

## 关键：**不要复制粘贴**，要换一个切入角度

小红书会检测重复内容，**完全一样的图文重发可能被判重复**。

## 标题（换成"人味"的）

```
两根绳摆一起给你看：主绳和辅绳到底差在哪
```

或

```
一次搞懂主绳和辅绳，我把它们摆在一起对比了
```

> 💡 **小红书标题 ≠ 抖音标题**。
> 抖音要钩子（"选错要命"），小红书要**像朋友在分享**（"我摆一起给你看"）。

## 封面

同上（三个选项）。

## 文案（小红书版 —— 更口语、更人味）

```
一直有人问主绳和辅绳的区别，干脆把它俩摆一起讲清楚。

【主绳】就记住 4 件事
1. 只买动力绳 —— 静力绳不能用来攀岩
2. 单绳 / 半绳 / 双子绳 —— 看绳头标签那个圈就能认
3. 直径：新手 9.6-10.2mm，别贪细
4. 长度：不确定就 60m

【辅绳】3 个尺寸
· 6-7mm  —— 灵敏，适合进阶
· 7-8mm  —— 新手首选，好抓
· 9-10mm —— 不划算，不如买短主绳

一条铁律：绝对不能用辅绳去先锋、顶绳攀岩。

（我做的是攀岩装备科普，有问题评论区问我）

#攀岩 #攀岩装备 #攀岩绳 #新手攀岩 #户外运动
```

# 🎯 这次测试的真正价值

**它验证的不只是一条内容，是一条可复用的规律：**

> 如果你的内容在抖音和小红书**表现差很多**，
> 那不一定是"平台不适合"，很可能是**你在用抖音的包装方式做小红书**。

**验证了这条，以后每一条内容你都能"一次拍摄、两套包装"：**
- 抖音：图解封面 + 钩子标题
- 小红书：照片封面 + 分享口吻
