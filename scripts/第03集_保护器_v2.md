# 📌 标题（v2）

## 主推

```
保护器怎么选？避开这 3 个坑
```

**为什么**：
- **"避坑"是你验证过的词**（「用好ATC！上方保护避坑关键细节」7,669）

```
A. 保护器买错，出事时它救不了你        ← 后果型，更冲
```

## 第 2 张｜先分清：什么是保护器

```
运动攀岩的保护器只有两类
不是「牌子不同」，是「原理不同」

① 管式（手动制动）
   ATC / Reverso / ATC-Guide
   制动靠你握住制动端

② 辅助制动（凸轮辅助）
   龟龟 GriGri / Revo / Jul
   受力时凸轮会咬住绳子
```

### ⚠️ 特别说明：8 字环不是保护器

```
8 字环不是保护器，是下降器

它用在绳降、救援。
运动攀岩的保护不要用 8 字 ——
绳易扭、制动差、给绳不顺手。

看到有人拿 8 字保护，那是很老的做法了。
```

**画面**：上排两个保护器（ATC / 龟龟）+ 下排单独画出 8 字，用红框标"不是保护器"

---

## 第 3 张｜坑 ①：绳子太细，龟龟咬不住

```
坑 ①  绳子太细，龟龟制动失效

龟龟对绳径有要求（一般 8.5–11mm）
绳子太细 → 凸轮咬不住 → 出事时锁不住

⚠️ 买之前先确认你自己绳子的直径
```

**画面**：龟龟 + 绳子的特写，标注"绳径必须在适用区间内"

---

## 第 4 张｜坑 ②：以为龟龟是"自动"的

```
坑 ②  以为龟龟是自动保护器

它不是。

制动端一样不能松手。
凸轮只是「辅助」——
你松手 = 人还是掉下去。
```

**⚠️ 这张是全篇最重要的一张**（保命信息）

---

## 第 5 张｜坑 ③：买了龟龟，结果要爬多段

```
坑 ③  买了龟龟，结果要爬多段

龟龟：单绳专用，不能双绳下降
管式：单绳 / 双绳都能用

如果你以后要去户外爬多段 →
先买管式（带向导环的款）
```

---

## 第 6 张｜按场景选（三档）

```
你在哪攀？→ 买什么

岩馆顶绳为主        → 龟龟（容错高）
户外运动攀 / 想学技术 → 管式（带向导环）
两边都要            → 先买管式，再加龟龟
```

---

## 第 7 张｜结论页（**收藏钩子**）

```
直接说结论

只做岩馆顶绳   → 龟龟
想学技术/去户外 → 带向导环的管式
两个都要       → 先管式，后龟龟

硬性检查（缺一不可）
□ 绳径匹配（你的绳子在适用区间内）
□ 单绳 / 双绳 搞清
□ 有没有向导环

⚠️ 8 字环不要作为保护器 —— 它只是下降器

买之前把这一页存下来，照着对
```
