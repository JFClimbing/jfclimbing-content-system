## 🎨 通用规则（整篇一致）

| 项 | 规则 |
|---|---|
| **底色** | 橄榄绿（沿用系列） |
| **字体** | 手写体（跟主锁/主绳一致） |
| **签名** | 每张右下角「**峰**」 |
| **集数** | 每张或封面标「第 3 集 · 攀岩装备基础篇」 |
| **照片** | 都用**实拍**，不要网上盗图 |

---

## 📷 先准备这 6 张实拍素材

拍一次就够，后面所有集都能用：

```
① ATC（橙色或任意管式）—— 单独摆拍，白/木背景
② 龟龟 GriGri —— 单独摆拍
③ 8 字环（有就拍，没有可跳过）
④ 绳子（你的 Beal 蓝绳）
⑤ 手穿绳进龟龟（第一人称视角）
⑥ ATC 穿双绳的俯拍
```

> 💡 **顺光拍**（窗边就行），不要打闪光灯。
> 背景干净（桌面、木地板、深色布都行）。

# ✂️ 贴纸使用原则（三条）

| 原则 | 说明 |
|---|---|
| **① 一页最多 2 个贴纸** | 多了就乱。宁可少 |
| **② 贴纸只做"强调"，不做"装饰"** | ⚠️❌✅☑️ 是强调；花花绿绿的装饰贴纸不要 |
| **③ 表情包慎用** | 只在"破冰/自嘲"场景用（像第 0 集那样）。**技术选购类不要** |

---

# 📋 制作顺序建议（省时间）

```
① 先拍 6 张实拍素材（20 分钟）
② 先做第 2、4、7 三张 ← 这三张承载核心价值
③ 再补第 1、3、5、6、8
④ 最后统一检查：底色 / 字体 / 签名 / 集数 是否一致
```

> 💡 **如果时间不够**，至少把 **第 2、4、7** 三张做到最好 ——
> 分类（懂）、保命（记住）、结论（存）——
> 这三张撑起整篇的价值。
