## 二、描述（523 字 / 上限 1000，直接复制）

```
买保护器，最多人问的一句是：我到底该买 ATC 还是龟龟？

这个问题问早了一步。不管你买哪个，先避开下面 3 个坑——它们跟品牌、跟价格都没关系，只跟你怎么用、在哪用有关。

坑① 绳子太细，龟龟制动失效
龟龟对绳径有要求：一般 8.5–11mm，最佳 8.9–10.5mm。绳子太细，凸轮咬不住，出事时锁不住；太粗（超过 11mm）也塞不进去。
买之前把设备翻过来看刻字，适用区间都写着。

坑② 以为龟龟是"自动"的
它不是。"辅助制动"这四个字里，重点是"辅助"。凸轮只是辅助，锁不锁得住不能赌——制动端一样不能松手，这一点 ATC 和龟龟完全相同。

坑③ 买了龟龟，结果要爬多段
龟龟单绳专用，不能双绳下降；管式单绳、双绳都能用。以后要去户外爬多段，先买管式（带向导环的款）。

怎么选：
· 只做岩馆顶绳 → 龟龟
· 想学技术、要去户外 → 管式（带向导环）
· 两个都要 → 先管式，后龟龟

必须确认（缺一不可）：
□ 绳径匹配（看设备上的刻字）
□ 单绳还是双绳，搞清
□ 管式有没有向导环

认准 UIAA / CE 就行，价格按预算挑。

顺便澄清一个常见误解：8 字环是下降器，不是保护器，别拿它做保护。

最后一句最重要：先用 ATC 练熟五步保护法，再考虑换装备。保护器只是工具，手法才保命。

你现在用的是 ATC 还是龟龟？评论区聊聊。
```
