## 二、正文（含 CTA 三件套）

```
扁带的坑不在买贵，在买错。

先分清三种：

· 散扁带 —— 成圈卖，按米裁，自己打结
· 快挂扁带 —— 连两个锁扣组成快挂，10-25cm
· 成型扁带 —— 厂家缝好，60 / 80 / 120 / 150cm

新手直接买成型扁带，长度 120cm。

为什么不是散扁带：
扁带打结以后，强度只剩 45%-60%（圆绳能保留 60-80%）。
扁带是扁的，一弯折，应力全集中在那一点上。
所以能用成型就别打结，能不打结就别打结。

然后是材质，这里有个反常识的地方：
聚酯（尼龙）扁带宽 19mm，迪尼玛（大力马）扁带宽 10mm，
两者都是 22kN。

也就是说，同样一个强度数字，宽度差了一倍。

迪尼玛这么轻、这么细，代价有三个：
① 几乎没有延伸性，不吸冲击
② 打结后强度掉得更狠
③ 怕磨、怕热 —— 接触尖锐岩角、或者被绳子高速摩擦，更容易出事

一句话：
新手买 19mm 聚酯成型扁带，120cm。
进阶、要走长线、在乎重量，再考虑迪尼玛。

长度怎么选：
60cm 做延长、挂保护点
120cm 搭保护站、绕大树，最通用
150cm 以上，特殊场景

颜色只代表长度，不代表强度 —— 别用颜色判断能不能用。

必须确认（缺一不可）：
□ 认准 CE EN 566
□ 缝线起毛、有切口、沾过化学物 → 直接退役
□ 散扁带打的水结要留足尾长，每次检查

什么时候必须换：
□ 缝线起毛、断线、发白
□ 扁带有切口、被磨薄、边缘起毛
□ 沾过化学物（汽油、酸、强碱）
□ 经历过一次大冲坠

买之前把这条收藏一下，照着对；
身边要去户外搭保护站的朋友，转给他 —— 这条能救命。

你现在用的是成型扁带还是散扁带？评论区说说。
```

### 第 3 张｜长度怎么选

```
长度对应场景

60 cm  → 延长、挂保护点
120 cm → 搭保护站、绕大树 ✅ 最通用
150 cm+→ 特殊场景

```

> ⭐ **"颜色只代表长度"这句是纠错的** —— 很多新手以为红色更结实。
> **"白色≠迪尼玛"也要单独写** —— 防止新手只看颜色选材质。

### 第 4 张｜⭐ 同样 22kN，宽度差一倍

```
同一个强度，两种宽度

聚酯（尼龙）   19mm   →  22 kN
迪尼玛（大力马）10mm   →  22 kN

宽度差了一倍，强度一样

（两条扁带并排，标出宽度和 kN）
```

> ⭐ **这张是全集的"钩子页"。** 两条扁带平铺一条对比，
> 左边标 19mm、右边标 10mm，两个都标 22kN —— 一眼就震住。

### 第 5 张｜迪尼玛的三个代价

```
迪尼玛轻，但有三个代价

① 几乎没有延伸性
   不吸冲击，静态受力更硬

② 打结后强度掉得更狠
   比尼龙掉得多

③ 怕磨、怕热
   接触尖锐岩角、被绳高速摩擦
   更容易出事

（三个小图标 + 一句话）
```

### 第 6 张｜⭐ 为什么选择成品扁带

```
成型扁带 vs 散扁带

成型扁带：
✅ 厂家缝好，直接能用
✅ 缝线经过专业工艺，强度有保障
✅ 尾部处理过，不容易开线
❌ 长度固定，要多种长度得买多条

散扁带：
❌ 需要自己打结
❌ 打结后强度会掉（水结：45%-60%）
❌ 结的位置受力集中
✅ 便宜，可以按米裁剪
✅ 一条长的能裁成好几条

新手直接买成型扁带
120cm 一条就够
要多种长度再补第二条

（画面：成型扁带（缝好的）vs 散扁带（要打结的）并排）
```

> ⭐ **新手买成型扁带，这个结论必须给清楚。**
> 说清理由：不用打结（不掉强度）、不用学水结、不用管尾长。
