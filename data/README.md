| `dy_works_2026-09-21.json` | 快照 |

| `dy_works_2026-09-23.json` | **最新快照（20 条）** |
| `prediction_registry.json` | 预测登记表 —— `dy_review.py` 用它自动对答案 |

**每个作品的字段**：播放 · 点赞 · 评论 · 分享 · 收藏 · 划走率 · 文案展开率 · 平均浏览图片数 · 吸粉量

> ⚠️ **务必用 `num` 字段，不要用 `raw`** —— 后台会用「1万」这种缩写，
> `raw` 里是字符串，`num` 是归一化后的数字（`1万` → 10000，`1.2万` → 12000）。
> 这个坑踩过一次：把「1万」当成 0 解析，导致相关系数算错。
