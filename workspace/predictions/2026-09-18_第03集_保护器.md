### 理由

**加分**
1. **标题是「避坑」型** —— OBS-016 强信号：避坑/场景/后果型 ≈ 名称型的 3-5 倍
2. **8 张** —— 落在已验证的「有效张数上限」内（主锁 8 张 48.9% < 主绳 10 张 53.6%）
3. **保护器是她的内容资产最厚的一块** —— 保护系统类历史 8 条合计 46,492 播放，均值 5,800（>baseline 2.1 倍）
4. **合集第 3 集 + 第 0 集入口导流**（第 0 集 09-18 发）
5. **结论页带收藏钩子**（主锁收藏/点赞 60.6% 是账号最高）

**减分**
1. 标题前半「保护器怎么选」仍是说明型，钩子力弱于「保姆级」「秘密武器」
2. 第 6/7 张结论重复 → 中段信息密度下降，可能拉低浏览张数
3. 第 4 张（保命信息）没有按设计做成最醒目的一页
4. 距第 0 集仅 2 天，账号流量池可能处于消化期
5. **未知变量**：若改为一周三发，单条流量是否被摊薄（本次无法分离）

### 核心诊断（五条）

**① composite 与实绩完全脱钩 —— 本项目迄今最强的一次证伪**
composite **8.6（当时全系列最高）** → 实测 **2,627**（装备系列倒数第二）。
预测时给的加分理由（"保护器是内容资产最厚的一块，历史保护系统类均值 5,800"）**全部没有兑现**。
→ **composite 不能用于决定"要不要发"，也不能用于排期优先级。**

**② AB=5 用错了对象**
预测给 AB=5，理由是「保护器是天天用的必备装备，受众最广」。
但实测比 **AB 更低的主绳（3,320）还差 20%**。
→ **AB（受众广度）不是装备系列播放的主驱动因子。** 原本拟验证的 H-安全带-01 提前被否掉一半。

**③ 结论页零数字 → 收藏/点赞 31.6%（预测 63%，腰斩）**
结论页原话：「价格按你预算挑，认准 UIAA / CE 就行」——**全篇零数字**。
对照主绳（结论页有 60m/9.8mm/¥600–1200）收藏/点赞 **52%**、主锁 **57%**。
→ 这是 **OBS-025（可存档性 = 结论唯一 × 结论带数字 × 结论在最后一页）** 的第一条硬证据。

**④ ⭐ 评论/点赞 33.3% —— 全账号最高**
6 评 / 19 赞。对照主锁 8/124 = **6.5%**、主绳 7/73 = **9.6%**。
→ 观众的评论是**提问式**的（「那到底买哪个？」），不是认同。
→ 派生 **OBS-024：评论/点赞比 = 内容是否闭环的诊断器**。

**⑤ 避坑型标题未在「新内容」上复现 —— OBS-016 需大幅复核**
装备系列新内容按播放排序：

```
主锁  保姆级科普，新手快码住      8,620   ← 保姆级
主绳  主绳+辅绳，一篇讲透        3,320   ← 说明型
保护器 避开这3个坑              2,627   ← 避坑型  ❗
第0集 别急着买齐                1,427
```

**避坑型排在说明型后面。** OBS-016 说「避坑型是装备名型的 3–5 倍」——那是**从旧视频数据（5–8 月）反推**的，
可能混杂了发布时间 / 账号权重 / 形态迁移。**在新内容上未复现。**
