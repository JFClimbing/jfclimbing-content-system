### 理由

**加分**
1. **标题是「避坑 + 数量」双钩子** —— 「新手最容易搞错的 3 个地方」命中 OBS-016 的强信号组（避坑型 7,669 / 场景型 7,049）

3. **金属件/技术装备是账号最强的一块** —— 主锁 8,384 是全账号技术装备最高
4. **内容里有两个反常识点** —— ①"为什么不能用一个主锁"（新手高频疑问）②"柱门 vs 钢丝门轻 10% / 开口大 3mm"（硬数据反差）
5. **结论页带强收藏钩子** —— 3 组打勾清单 + 「存这一页」
6. **合集第 0 集入口 + 第 3 集（09-20）紧邻导流**
7. **09-22 临近国庆**，户外内容流量上行期

**减分**
1. **画布从 9:16 换成 3:4（首次）** —— 图不铺满全屏，**封面在信息流里可能变小、冲击力下降**，这是本集最大的未知变量
2. **快挂受众比保护器窄** —— 保护器是"天天用"，快挂是"户外才用"，室内新手用不到
3. **距第 3 集仅 2 天** —— 一周三发，流量池是否被摊薄（上次已有此疑问，仍未分离）
4. **周二 19:30 vs 第 3 集的周日** —— 周末/节前的户外流量更高
5. 标题前半「快挂怎么选」仍是名称型
6. 第 6 张文字压在主体上 → 可能拉低浏览张数
7. 第 7 张自查清单原缺「朝向」（已建议补）

## 核心诊断（四条）

### ① 我把两个减分项判反了 —— 这是 +118% 的直接原因

| 预测时写的减分项 | 实际结果 |
|---|---|
| 「画布 9:16 → 3:4 首次，封面在信息流里可能变小、冲击力下降」 | ❌ **判反**：3:4 带来全系列最低划走率 **42.32%** |
| 「快挂受众比保护器窄，室内新手用不到」 | ❌ **判反**：快挂 12,000 vs 保护器 3,422（**3.5 倍**） |
| 「距第 3 集仅 2 天，一周三发摊薄流量」 | 未发生 |
| 「周二 19:30 vs 周日，户外流量低」 | 无影响 |
| 「标题前半仍是名称型」 | 后半「新手最容易搞错的 3 个地方」足够强 |

> ⭐ **教训：我把"未知变量"（首次换 3:4）直接当成了"减分项"。**
> 正确写法是**记为不确定、不押方向**。这条已写进流程规范（OBS-040）。

### ② 划走率是先行指标 —— 第二条硬证据

| 集 | 划走率 | 播放 |
|---|---:|---:|
| **快挂** | **42.32%** | **12,000** |
| 保护器 | 47.07% | 3,422 |
| 主锁 | 48.39% | 8,829 |
| 主绳辅绳 | 51.63% | 3,483 |
| 第0集 | 56.86% | 1,490 |

剔除尚未定稿的扁带（n=5），**ρ(播放, 划走率) = +0.70**（划走率越低、播放越高）。
→ 加上全量 19 条的 −0.501，**OBS-004 现在有两组独立证据**。

### ③ ⭐ 播放爆炸但收藏率垫底 —— 收藏与播放是两条独立的轴

```
快挂：播放 12,000（全系列第 1）   收藏率  0.49%（倒数第 2，仅好于第0集）
主绳：播放  3,483（第 3）        收藏率  1.21%（全系列第 1）
```

快挂结论页只有「贵约 20%」这个**相对数字**，没有**绝对价格区间**。

```
完整价格表（主绳）→ 1.21%
无价格（主锁）    → 0.84%
仅相对数字（快挂）→ 0.49%
零价格（保护器）  → 0.35%
```
→ **OBS-036（结论页价格表 ↔ 收藏率）再获一票。**

### ④ 文案展开率与播放无关

快挂展开率 **0.55%**（全系列最低）却播放最高；主锁 3.68%、主绳 3.84% 都在低播放组。
→ 展开率反映的是**正文长短**，不是内容质量。**不要用它判断成败。**
