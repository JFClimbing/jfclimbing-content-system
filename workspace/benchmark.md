## 基础 rubric 派生（init 时一次性，**仅给定性方向**）

> 基于 5 条对标样本，总结哪些维度看起来跟"高表现"相关。
> **不直接给数值权重**——5-10 样本数值拟合容易过拟合。

### 高表现样本共有的维度（看起来重要）

- **AB (问题普遍性) 高** — 2/2 高样本都是"人人必须买的基础装备"（登山三件套 / 绳子）；2/2 低样本都是"进阶玩家才关心的系统设计"（自保 / 安全带）。分野最清晰的一个维度。
- **HP (钩子 / 需求锚定) 高** — 高样本标题直接锚定需求：`1000都不到`、`看完就再也不用问其他人啦`；低样本标题是裸产品名（`攀登自保推荐` / `攀索Whisper`），没有利益点。
- **QL (可复制内容密度) 高** — 高样本直接给"买什么"，观众能抄作业；低样本讲原理。评论区行为佐证：高样本评论是报型号（`性价比之王sg50` / `mh590真的好用`），低样本是求解（`菊绳的作用和编带一样吗`）。
- **SAT (教学人格) 高** — 数据最好的两条都带强人格标签（`穷鬼` / `我是发明大王` / `要什么自行车`）；低样本零人格。

### 低表现样本共有的维度（看起来不太重要）

- **SR (趋势共振) 不显著** — 5 条全是同一类装备推荐，SR 分布无差异，无法解释表现差异。
- **NA (递进感) 不显著** — 单集推荐均为并列结构，没有递进弧线，高低样本无差异。

### Claude 给的初始建议

- 该账号是 **「大众刚需 + 价格锚点 + 自嘲人格」驱动型**，不是「技术权威」型。爆发靠**帮观众省事省钱**，不是讲得深。
- 若将来 bump，候选调整方向：`AB / HP / QL / SAT` 相对 `SR / NA` 上调。
- **但请等你自己跑 5+ 篇校准再正式 bump**——5 个对标样本不足以下结论。

## 选题方向感

> 找选题 brainstorm 时会读这里。

对标账号的主题分布：

- **装备推荐 / 选购清单**（占比 100%）— 系列连载「第 N 集」
- 细分为三类：① 大众刚需清单（三件套 / 绳子）② 单品评测（安全带 / 头盔 / 背包）③ 自制省钱方案（冰洞钩）

**调性**：直白、自嘲式省钱、有梗、作者高频回复

**核心公式**：
```
预算锚点（越夸张越好）
  + 大众刚需装备（不是进阶玩家的东西）
  + 直接给购买答案（不要留悬念）
  + 网络梗 / 自嘲人格包装
  + 系列编号（追更）
```

**明确避开**：抽象原理讲解（用户标记的"低"样本全是这个）

> 你不一定要做完全一样的主题——这只是个 reference frame。
