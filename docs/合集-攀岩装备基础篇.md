## 一、核心框架：**保护链（The Safety Chain）**

**攀岩的所有装备不是一张"清单"，是一条"链"。**

```
        人
         │  ① 安全带      ← 贴身，承载人体
         │
         │  ② 主锁        ← 链上第一个「可拆卸」节点
         │
         │  ③ 保护器      ← ATC / 龟龟，控制绳的摩擦
         │
         │  ④ 主绳        ← 能量吸收 + 连接（唯一不能省的）
         │
         │  ⑤ 快挂        ← 连接绳与岩壁（散锁 + 扁带）
         │
         │  ⑥ 保护点      ← 岩壁上的锚（不可拆）
        岩壁
```

### 为什么用这个框架

| 好处 | 说明 |
|---|---|
| **每集都有位置** | 观众看任何一集，都知道"我在学链条的第几环" |
| **天然递进（NA=5）** | 自己的高播放公式就是"完整系统教学"，链条天然是系统的 |
| **可无限扩展** | 以后加"头盔""粉袋""攀岩鞋"都能挂上去 |
| **形成追更理由** | 链条没走完 = 观众有理由跟着你 |
| **对应抖音机制** | 「合集」功能本身就是这个逻辑，内容和机制同构 |

### ⚠️ 关键决策：发布顺序 ≠ 链条顺序

**链条顺序**是逻辑的（人 → 岩壁）。
**发布顺序**要兼顾「她已发主锁」和「制作成本」。

主锁放在开头是**对的** —— 因为它是最简单、最具体、最容易画的那个"零件"。
先让人认识一个零件，再拼装成系统，比先讲系统再拆零件更好懂。

### 第 2 集为什么是「主绳」

理由有三条，按重要性排：

1. **因果承接最强** —— 第 1 集说主锁"用于连接保护器、建立保护站"。
   那连的是**什么**？→ 绳。这是最自然的追问。
2. **它是唯一不能省的装备** —— 主锁可以凑合、安全带可以借，**绳子不行**。
   这个"不可替代性"本身就是最强的钩子。
3. **受众最广（AB=5）** —— 所有攀岩者都要买绳，比保护器/快挂更刚需。

> ⚠️ 但注意：绳是**复杂度最高**的一集（动力/静力、单/双/半绳、直径、长度、绳皮绳芯）。
> **如果一集讲不完，就拆成两集**：
> - 2a 主绳怎么选（类型 + 直径 + 长度）
> - 2b 主绳的寿命与退役（什么时候必须扔）← 也是花钱决策，自带价格锚点

## 三、统一模板（每集结构一致）

**这不是可选项 —— 结构一致才能让观众形成预期、降低你的制作成本。**

```
① 封面          本集装备名 + 一句话结论（大字）
② 是什么/分几类  核心分类维度（主锁=形状；绳=动力/静力；保护器=自锁/手动）
③ 什么时候用     每种类型 → 对应场景（这是「实用清单 UL」的核心）
④ 新手易错点     3-5 个「最容易买错 / 用错」的点 ← 这是「钩子 HP」的核心
⑤ 直接给答案     价格区间 + 具体型号建议（不要留悬念）
⑥ 链条定位       本集在第几环 + 下一集预告
```

### 第 ⑥ 段的具体写法（这是系列的关键机制）

结尾固定一句话，形状不变：

> 「这是攀岩装备基础篇的**第 2 集**。它站在保护链的**第四环**——
> 上面接着**主锁**（第 1 集），下面连着**快挂**（第 4 集）。
> **下一集讲保护器：ATC 和龟龟到底差在哪。**
> 想一次把装备搞明白的，关注这个合集。」

**为什么这句话重要**：
- 它把「合集」从"一堆散片"变成"一条可以追的线"
- 它给了**明确的关注理由**（不是"求关注"，是"还有 X 没讲"）
- 它把新观众的"还差什么"变成回访动机

> 📌 你现在的转化率只有 0.155%（65k 播放 → 101 粉）。
> **这句话就是转化率最便宜的提升手段** —— 零额外制作成本。

## 四、第 2 集「主绳」详细大纲

> 按上面模板填。这一集的信息量比主锁大，建议**控制在 8-10 张图**。

### 封面
大字：**主绳怎么选？一期讲透动力绳 / 静力绳 / 单双半绳**
（沿用主锁那条的封面范式：分类名 + 一句话结论）

### 第 1 张：先分清动力 vs 静力（最重要的一条）
- **动力绳**：会拉伸，攀岩用（吸收冲坠能量）
- **静力绳**：几乎不拉伸，绳索作业 / 下降 / 救援用
- ⚠️ **用静力绳攀岩 = 致命**（冲坠力直接传到人身上）
- 一句话结论：**攀岩只买动力绳**

### 第 2-3 张：动力绳的三种类型（UIAA 标准）
| 类型 | 直径 | 用法 | 新手需要吗 |
|---|---|---|---|
| **单绳** | 8.9-11mm | 单股使用，运动攀/顶绳 | ✅ **只买这个** |
| **半绳（双绳）** | 7.8-9mm | 双股交替挂，传统攀/长路线 | ❌ 暂不需要 |
| **双子绳** | 7.5-8.5mm | 双股同时挂 | ❌ 暂不需要 |

### 第 4 张：直径怎么选
- 越粗：耐磨、好抓、寿命长，但重
- 越细：轻、顺滑，但不耐磨、对保护技术要求高
- **新手建议：9.6-10.2mm**（好抓、耐用、不挑技术）

### 第 5 张：长度怎么选
- 60m：大多数岩馆 + 多数运动攀路线（**最通用**）
- 70m：很多现代路线需要
- 80m：特定长路线
- **先确认你常去的岩馆/岩场要求多少米，再买**

### 第 6 张：结构（一句带过，别展开）
- 绳皮 + 绳芯；绳皮决定耐磨，绳芯决定强度
- 干绳处理（防水防冰）要不要加钱 → 运动攀室内可不加

### 第 7 张：新手最容易犯的 3 个错
1. 买静力绳当攀岩绳（**致命**）
2. 只看价格不看直径（买了 9.2 的细绳，抓不住、磨得快）
3. 绳子没标注 UIAA / CE 认证

### 第 8 张：直接给答案
- 价格区间（入门动力绳大概多少钱）
- 一句话建议：「**先买一条 60m / 9.8mm 的单绳，够你用两年**」

# 八、最终采用的分类（用户 2026-09-14 定稿）✅

> ⚠️ **本节是定稿，前面的"单向保护链"设计作废。**
> 采用**两分法**：个人装备 / 技术装备。

## 分类结构

### 一、个人基础装备（穿在身上的）

| 装备 | 说明 |
|---|---|
| **攀岩鞋** | 橡胶底，贴合但不过分挤脚 |
| **安全带** | 攀岩专用，腰环 + 腿环，用于连接绳子 |
| **粉袋 + 镁粉** | 吸汗防滑；有些场馆要求用粉球 |
| **头盔** | 户外攀岩、传统攀、顶绳/多段攀建议佩戴，防落石和撞击 |

### 二、绳攀技术装备（连接系统的）

| 装备 | 说明 |
|---|---|
| **动力绳** | 用于攀登和保护，必须有 UIAA/CE 认证，不能用静力绳代替 |
| **保护器** | 如 ATC、GriGri 等，用于下降和保护 |
| **主锁** | 至少几把，常用 HMS 梨形丝扣锁/自动锁 |
| **快挂** | 运动攀用，由两个锁扣和一条扁带组成 |
| **扁带 / 绳套** | 用于建站、延长锚点、做个人保护等 |

## 关键约定

1. **「保护链」这个词只指技术装备那条链**（主锁 → 主绳/辅绳 → 保护器 → 快挂 → 扁带 → 牛尾/自保）。
   **安全带不属于它** —— 安全带是个人装备。
2. **两类都放在同一个合集里**，但**分开讲**。
3. **第 9 张（链条定位页）只画技术装备这 6 环** —— 不画安全带、不画保护点。
4. 「绳攀技术装备」这个限定词是有意的 —— 暗示**只玩抱石的人不需要第二类**。
