# 指力训练 · Hangboard Timer

> 一个单页的指力板（fingerboard）训练计时器。
> 打开即用，可加到手机主屏当 App。

---

## 在线使用

部署后地址形如：`https://<github用户名>.github.io/jf-hangboard/`

---

## 功能

### 训练法预设

**指力板（Fingerboard）**

| 预设 | 挂 | 休息 | 组次 |
|---|---|---|---|
| **指力板 · 开握 7:50** | 7 秒 | 50 秒 | 6 次 × 3 组 |
| **指力板 · 半抠 5:55** | 5 秒 | 55 秒 | 5 次 × 3 组 |
| **指力板 · 开握+半抠轮换** | 7 秒 | 50 秒 | 6 次 × 3 组（两种握法自动交替）|

**手臂 + 背部（计次模式）**

照原始配方，按**次数**做，不是按时长：

| # | 动作 | 目标 | 组数 | 组间休息 |
|---|---|---|---|---|
| 1 | 引体向上 | 8–12 次 | 3 | 90 秒 |
| 2 | 俯卧撑 | 12–15 次 | 3 | 90 秒 |
| 3 | 澳式划船 | 10 次 | 3 | 90 秒 |
| 4 | 小臂静态弯举 | 15 次（顶峰停 2 秒） | 3 | 60 秒 |
| 5 | 平板支撑 / 侧平板 | 30–60 秒 | 3 | 60 秒 |

**计次模式怎么用**：悬挂/引体这类**不计时**，屏幕上正计时走秒，你做完这一组
点 **「完成本组」** → 自动进入休息倒计时 → 完成后自动进下一组，并念出下一个动作名。
只有平板支撑是计时的（45 秒）。

**自定义** —— 所有参数和动作自己填。

### 可调参数

- **单次悬挂** 1–60 秒
- **间隔休息** 1–120 秒
- **循环次数**（每组几次）1–20
- **组数** 1–12
- **组间休息** 10–600 秒
- **开始热身** 0–900 秒
- **结尾放松** 0–900 秒
- **开始倒数** 0–15 秒

### 动作轮换

可自定义动作列表（开握 / 半抠 / 全抠 / 捏握 / 口袋 …），**每次悬挂自动轮换**，屏幕上显示当前该用哪个握法。

### 语音播报 ⭐ 新增

- **倒数播报**：最后 3 秒朗读「三、二、一」
- **阶段播报**：开始 / 休息 / 下一组 / 训练完成，会自动念出来
- 循环训练时**直接念动作名**（引体向上、俯卧撑…），不用盯着屏幕

### 背景音乐 ⭐ 新增

- **选文件就行**：音频（mp3/m4a/wav）或**视频**都能选，视频会自动只播声音
- **音量可调**（0–100%）
- ⭐ **自动压音**：播报倒数和阶段提示时，音乐自动压到 15%，说完再恢复 —— 保证播报永远盖得住音乐
- 文件存在浏览器本地（IndexedDB），刷新后还在
- 关掉网页再打开，会重新加载上次选的音乐

### 其他提示

- **提示音**：阶段切换、最后 3 秒倒数
- **震动**：需要手机支持
- **屏幕常亮**：训练中不自动锁屏（Wake Lock API）

### 训练记录

完成的训练自动存本地（localStorage），显示最近 8 次：日期 / 训练法 / 组×次×秒 / 总时长。

### 快捷键（电脑端）

- `空格` 开始 / 暂停
- `R` 重置
- `→` 跳过当前阶段

## 技术说明

### 为什么用「绝对时间戳」而不是计数器

早期版本用 `requestAnimationFrame` 累加时间，结果：

- **手机锁屏 / 切到后台时，rAF 会被系统暂停** → 计时器停住，回来时时间不准
- 普通 `setInterval` 累加也会因节流丢失时间

现在改成：**记录每个阶段的绝对结束时刻 `segEndAt`**，
每次 tick 用 `(segEndAt - now)` 反算剩余。即使被节流，回来后立即校准到真实进度。

### 为什么音乐走 Web Audio

iOS Safari 里 `<audio>` / `<video>` 的 `.volume` 是**只读**的 —— 设了没用，永远满音量。

所以音乐改用 **Web Audio API**：把文件解码成 `AudioBuffer`，用 `GainNode` 控制音量。
这样 iOS 上也能真正调音量，倒数和音乐的音量差才拉得开。

```
文件 → decodeAudioData() → AudioBuffer → BufferSource(l循环) → GainNode → 输出
                                                              ↑
                                                    音量 / 压音都调这里
```

视频文件没法 decode，会退回 `<video>` 播放（那种情况下音量控制失效，但能出声）。

## 部署到 GitHub Pages

```bash
# 1. 建仓库（public）
gh repo create <用户名>/jf-hangboard --public --description "指力训练计时器"

# 2. 推文件
git init && git add . && git commit -m "init"
git remote add origin https://github.com/<用户名>/jf-hangboard.git
git branch -M main && git push -u origin main

# 3. 开启 Pages
gh api -X POST repos/<用户名>/jf-hangboard/pages \
  -f 'source[branch]=main' -f 'source[path]=/'
```

**地址：** `https://<用户名>.github.io/jf-hangboard/`

### 加到手机主屏（iPhone）

Safari 打开网址 → 分享 → **添加到主屏幕**

之后像 App 一样全屏打开，没有浏览器地址栏。

## 训练建议（不是医疗建议）

| 水平 | 建议 |
|---|---|
| 完全新手 | 先练 2–3 个月基础，指力板容易伤手指 |
| 入门 | 入门 6:4 低强度，每周 2 次，中间隔 48 小时 |
| 进阶 | Repeaters 7:3，每周 2–3 次 |
| 力量期 | Max Hangs，组间充分休息（3 分钟以上） |

**⚠️ 手指肌腱恢复很慢。疼就停，别硬撑。**
