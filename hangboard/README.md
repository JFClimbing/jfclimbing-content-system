# 指力训练 · Hangboard Timer

> 单页指力板 / 力量训练计时器。可加到手机主屏当 App。

**在线：** https://jfclimbing.github.io/jfclimbing-content-system/hangboard/

---

## 设计原则

**一个计划 = 若干「动作块」**，每个块自己带全部参数：

```
块 = { 名称, 类型(计时/计次), 时长, 次数, 次间休息, 组数, 组间休息 }
```

所以「7 秒 × 6 次 × 3 组」和「引体 8-12 次 × 3 组」是同一套模型，
只是 `类型` 和 `次数` 不同 —— 不需要两套逻辑。

---

## 内置计划

| 计划 | 内容 |
|---|---|
| **开握 7:50** | 7 秒 / 次间 3 秒 / 6 次 / 3 组 / 组间 2 分 |
| **半抠 5:55** | 5 秒 / 次间 5 秒 / 5 次 / 3 组 |
| **开握 + 半抠** | 上面两套连着做 |
| **手臂 + 背部** | 引体 → 俯卧撑 → 澳式划船 → 小臂弯举 → 平板，各 3 组 |

**变式可选**：引体（标准 / 反向划船 / 跳跃离心 / 离心）、俯卧撑（标准 / 跪姿 / 窄距）、平板（平板 / 侧平板）

```
┌─ 计时页 ──────────────┐

│                        │
│  ⏮  ▶  ⏭   歌名         │  ← 播放器（音量跟手机）

```

**六个格子全部可点，就地弹出面板修改，不跳页。**

## 关键实现

### 音乐用 `<audio>`，不用 Web Audio

iOS 上 `speechSynthesis` 播报会抢占音频会话。

- 用 **AudioContext** 播音乐 → 被打断后进入 `interrupted` 状态，`resume()` 不可靠，**必须手动重启**
- 用 **`<audio>` 元素** → 被打断只是 `pause`，监听 `pause` 事件重新 `play()` 即可

所以音乐走 `<audio>`，并在 `pause` 事件里自动接回来：

```js
bgm.addEventListener('pause', () => {
  if(expectPlaying && cfg.music && running && !paused){
    setTimeout(() => { if(bgm.paused) musicPlay(); }, 260);
  }
});
```

代价是不能单独调音量（iOS 上 `audio.volume` 只读），
所以**音量跟随手机音量键** —— 也符合直觉。

提示音和语音不受影响，继续用 Web Audio / 系统 TTS。

### 进度环

每 200ms 只更新 `stroke-dashoffset`，配合 CSS `transition: stroke-dashoffset .3s linear`，
在两次更新之间自动插值 —— 看起来是连续滑动，不会一跳一跳。

文字只在值变化时才写 DOM，避免无谓重排。
