# 一、⭐ 体系：4 门课 ↔ 4 季视频 ↔ 4 个合集

```
课程              视频季（抖音合集名）      条数    视频编号
─────────────────────────────────────────────────────────────
① 体验课    →    《野攀体验》          →    3      V1–V3
② 顶绳课    →    《顶绳系统》          →    5      V4–V8
③ 先锋课    →    《先锋进阶》          →    5      V9–V13
④ 结组课    →    《多段结组》          →    3      V14–V16
```

## ⭐ 为什么这样就是"体系"

| 旧版问题 | 本版解法 |
|---|---|
| 6 条并列，没有层级 | **4 季递进**，每季是一阶能力 |
| 视频和课程是两张皮 | **合集名 = 课程名**，观众刷完合集 = 上完那门课免费部分 |
| 观众不知道自己在看哪个阶段 | **每条结尾说"这是 XX 的第 N 条"** |
| 拍的时候不知道先拍哪条 | **按"好拍程度"分 4 批**，批次 ≠ 课程顺序 |

# 三、课程连接怎么做（不违和版）

## ❌ 不要这样做
> 「我把完整的顶绳系统做成了课程，想学的可以私信我」

## ✅ 这样做

**做法 1：合集名就是课程名**
```
抖音合集 → 《顶绳系统》    课程 → 《顶绳课》
观众不用被告诉，自然就连上了。
```

**做法 2：每条结尾说"位置"，不说"卖点"**
```
「这是《顶绳系统》的第 2 条。/
 这一季一共 5 条，讲完你就能自己搭一个顶绳站。」
```
← **说的是位置和承诺，不是价格和报名。**

**做法 3：把课程大纲当"路线图"放在简介**
```
抖音简介：野攀从 0 到结组，4 季：
① 体验 ② 顶绳 ③ 先锋 ④ 结组
新手问题评论区问，我看到就回
```

**做法 4：等他们问**
课上不上、什么时候上、多少钱 —— **不在视频里说**。
有人问「你教不教」的时候，才是时机。

# 🎬 V2｜岩场礼节：3 件没人当面说的事 ⭐（按你的纠正重写）

**季**：① 体验 ｜ **时长**：58 秒 ｜ **条件**：崖底，**不需要岩友**（可用 1 个朋友配合更好）

## 三个礼节（你给的）

```
① 他人在攀爬中，不要慢悠悠从保护员前方走过
② 想爬的路线，已经有人挂绳 —— 要先问
③ 垃圾不许乱扔
```

## 口播稿

**0:00–0:08**｜【画面：一个人慢悠悠从保护员前面走过，保护员扭头看他。慢镜头】
> 【不说话，只有脚步声】

**0:08–0:18**｜【对着镜头】
> 「这三件事，是岩场里没人会当面说你的。//
> 但**每一条都有人在乎**。」

**0:18–0:36**｜礼节①【画面：从保护员前方走过（错）→ 从保护员后方绕行（对）】
> 「**别人在爬的时候，别从保护员前面走。**//
> 你挡的不是路——//
> 是**他的视线**。//
> 保护员的注意力在外面那个人身上，/ 你一走过去，他就得看你一眼。//
> 就那一秒，上面的人掉了，他看不见。」

> 🔴 **这个是最重要的一条，给 18 秒。** 另外两条各 12 秒。

**0:36–0:48**｜礼节②【画面：指一条挂好绳的线 → 转头问旁边的人 → 对方点头】
> 「看到一条线，上面挂着绳——//
> **别直接上。先问一句。**//
> 那根绳说明已经有人在爬，或者在等。//
> 问一句，人家会让给你，或者告诉你还要等多久。//

**0:48–0:56**｜礼节③【画面：把地上的胶带 / 包装 / 镁粉块收进袋子带走】
> 「垃圾——**必须带走**。//
> 岩场不是景区，**没人来打扫**。//
> 你留下的东西，/ 会长在那儿好几年。」

**0:56–1:00**｜【对着镜头，一句话收】
> 「岩场是大家共用的。/ 你舒服，别人才舒服。」

## ⚠️ 拍摄要点

| 条 | 错的镜头 | 对的镜头 |
|---|---|---|
| ① | **慢悠悠**从保护员正前方走过（要真慢，走出"没意识到"的感觉） | 从保护员**身后**绕过去 |
| ② | 直接走过去要上墙 | **先问** —— 拍到你转头说话、对方回应 |
| ③ | ❌ **不要真的扔垃圾**（拍"地上有垃圾"就行） | 弯腰捡起来，放进包 |

## ⚠️ 需要配合吗
- **礼节①必须有人配合**（要有一个人当保护员）—— 如果约不到人，**改成一个人对着岩壁做动作 + 字幕说明**，但效果差一半。
- **礼节②③可以自己拍**（自己问、自己捡）。

## ⚠️ 待核实
开场那句「没人会当面说」——**如果你有真实被提醒过的一次，换成具体事件会强 10 倍**：
> 「有一次我刚走过去，就被人拉了一把——/ 当时我还不知道为什么。」

# 🎬 V3｜建站：在地面就能讲清楚 ⭐（按你的纠正重写）

**季**：② 顶绳 ｜ **时长**：58 秒 ｜ **条件**：⭐ **地面，不用上顶部**

> ⚠️ **本条的写法已经完全改掉。**
> 旧版说"只有一个主锁 = 错"，**这是错的**（见文末更正说明）。

## 核心知识（3 个点，全部正面讲）

```
① 锚点要≥2个，且互相独立
② 连接材料要有冗余（两条扁带 / 一根绳）
③ 汇聚点可以就是一个主锁 —— 这是标准，不是偷懒
   ⭐ 在结组里，所有人（保护者 / 跟攀者）都扣到这个主锁上
```

## 口播稿

**0:00–0:10**｜【画面：俯拍地面，两个挂片（或两个锚点） + 两条扁带 + 一个主锁，摆好】
> 「很多人以为建站要在顶上搭。//
> **其实这一套，在地面讲最清楚。**」

**0:10–0:34**｜【手部特写，边做边说，动作慢】
> 「第一步：**两个点**。//
> 两个点必须是**互相独立**的——/ 一个崩了，另一个还在。//
> 第二步：**两条扁带**，各自连一个点。//
> 这里要冗余，**不能一条扁带绕两个点**。//
> 第三步：两条扁带拉到一起，**找好角度**。//
> 夹角越小越好——/ 夹角一大，每个点受的力**成倍往上涨**。」

**0:34–0:50**｜【特写：主锁扣进汇聚点】
> 「最后，**汇聚点扣一个主锁**。//
> 有人会觉得：就一个锁，够吗？//
> 够。//
> **冗余是在前面那一层做的。**/ 两个点、两条扁带，冗余已经够了。//
> 汇聚点本来就是一个单点。」

**0:50–0:58**｜【对着镜头】
> 「而且这个主锁，**在结组里也一样用**——//
> 保护的人扣它，跟攀上来的人也扣它。//
> 这一条，是后面结组那一季的地基。」

**结尾位置句**：
> 「这是《顶绳系统》的第 1 条。」

## ⭐ 为什么改成"地面拍"

| | 上顶部拍 | **地面拍** |
|---|---|---|
| 成本 | 要爬上去 | ✅ 站着就行 |
| 画面 | 仰视，看不清结构 | ✅ **俯拍，结构一目了然** |
| 风险 | 高 | ✅ 无 |
| 可重拍 | 难 | ✅ 随便重来 |

> **地面拍完，观众看懂了结构；上顶部拍，观众只看到一双手和一片岩壁。**

## ⚠️ 地面怎么找两个点
```
优先：岩场底部的两个低位挂片
其次：两棵树的树干（系扁带）
再次：两个固定物（柱子等）
再不行：找朋友站两边拉住（仅作演示，字幕注明"演示用"）
```

## 🔴 更正说明（旧版错在哪）
```
❌ 旧版：「中间只有一个主锁」= 错误示范
✅ 事实：汇聚点是一个单点，这是标准做法。
        冗余要求落在「锚点」和「连接材料」两层，
        不是落在汇聚点上。
        你说的「在结组中是可以用的」是对的。
```

# 🎬 V4｜布林结：除了不好检查，全是优点 ⭐（按你的纠正重写）

**季**：② 顶绳 ｜ **时长**：58 秒 ｜ **条件**：⭐ 地面 / 家里

> ⚠️ **本条完全翻转。**
> 旧版说"我后来改用八字结"，**你是常用布林结的**，方向错了。

## 核心（3 个优点 + 1 个缺点）

```
优点 ① 受力之后好解 —— 八字结受力后极难解
优点 ② 绳尾用量少 —— 不占绳长
优点 ③ 打完不别扭、不卡 —— 绳路顺
缺点 ① 打错了看不出来 —— ⭐ 唯一的缺点
        对付办法：留长绳尾 + 打完回拉确认
```

## 口播稿

**0:00–0:10**｜【手里拿着打好布林结的绳，对着镜头】
> 「我最常用的结，是布林结。//
> 有人说它不如八字结稳——//
> **我不这么看。**/ 除了一个毛病，它全是优点。」

**0:10–0:38**｜【快剪三个优点，每个 8 秒，边做边说】
> 【优点①：做"受力后解开"的动作】
> 「**第一，受力之后它好解。**//
> 八字结吃上力，湿了、冻了，/ 有时候你解五分钟。//
> 布林结——一推一拉，开了。」//
> 【优点②：对比绳尾长度】
> 「**第二，它省绳。**//
> 八字结打完结会吃掉一截绳，/ 布林结几乎不占。」//
> 【优点③：摸一圈绳路】
> 「**第三，它顺。**//
> 不别扭、不卡绳，/ 抽绳的时候不跟你较劲。」

**0:38–0:54**｜【对着镜头，这一段慢一点】
> 「它只有一个毛病——//
> **打错了，你看不出来。**//
> 八字结打错了图形就歪了，一眼就发现。//
> 布林结打错了……/ **它看起来也挺像那么回事。**//
> 所以我的做法是：**绳尾留长**，/ 打完**回拉一下**确认。//

**0:54–0:58**｜【对着镜头】
> 「把这个动作做成习惯，/ 它就没有缺点了。」

**结尾位置句**：
> 「这是《顶绳系统》的第 2 条。」

## ⚠️ 待核实
