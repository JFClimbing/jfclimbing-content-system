# 一、先锁定三条「不可动摇」的结论

这次复盘跑出来的三条，**以后所有创作决策都要以它们为前提**：

## 结论 1：涨粉 ≈ 播放 × 0.2%

```
装备系列 9 条涨粉率：0.13% / 0.14% / 0.15% / 0.18% / 0.20% / 0.22% / 0.22% / 0.22% / 0.26%
→ 差不到 2 倍，几乎恒定
```

**含义：**
- ❌ **"把内容做得更好"不会提升涨粉率**
- ✅ 只有两件事能改这个数：**① 把播放做大 ② 让人想认识你（人格）**

## 结论 2：播放与收藏是**两条独立的轴**（ρ = +0.164）

```
主绳辅绳：播放倒数第 2（3,613）→ 收藏率第 1（1.16%）
快挂：  播放第 1（16,000）    → 收藏率第 5（0.49%）
```

**含义：**
- 想「要播放」→ 靠**标题钩子 + 选题热度**
- 想「要收藏」→ 靠**结论页的可抄内容**
- **一条内容不可能同时把两件事做到极致** → **发布前必须先定这条的 KPI**

## 结论 3：播放由「选题热度」驱动

```
高播放：快挂 16,000（可买好几把）· 主锁 8,989（入门第一件）
低播放：主绳 3,613（买一条用三年）· 保护器 3,528（一买一个）· 第0集 1,512（总览）
```

**含义：**
> **不是"这个问题多少人遇到"，而是"这件事多少人正在花钱"。**

# 二、⚠️ 三个必须改掉的旧习惯

## 改掉 1：**不再用"内容质量"解释涨粉**

**旧思路**（错）：
```
内容做得更好 → 观众更认可 → 涨粉更多
```

**新思路**（对）：
```
内容做得更好 → 完播/互动更好 → 播放更大 → 涨粉更多
                 ↑
           涨粉率本身不变（0.2%）
```

**→ 别再把"内容好不好"和"涨粉多不多"挂钩。**
**决定涨粉的是"有多少人看到"，不是"看到的人多喜欢"。**

## 改掉 2：**取消「全局 ×0.85 校准」**

装备系列平均绝对误差 **52.8%**，中位偏差 **−21.0%**。
−70% 和 +191% 互相抵消，所以中位数看着还行。

**→ 全局系数修不了 52.8% 的误差，只会掩盖个案。**
**→ 改成「逐集前置自检」**（见第四节）。

## 改掉 3：**结论页不许再出现"按你预算挑"这种话**

```
主绳辅绳（有完整价格表 ¥600–1200）→ 收藏率 1.16%  ← 第 1
保护器（"价格按你预算挑"）        → 收藏率 0.34%  ← 倒数第 2
扁带（全篇零价格）               → 收藏率 0.49%
快挂（只有"贵约 20%"相对数字）    → 收藏率 0.49%
```

**→ 结论页必须有「绝对数字」：价格区间 / 规格 / 时间 / 数量。**

# 三、⭐ 脚本结构 v2（每条都按这个写）

## 3.1 通用骨架（6 段）

```
① 钩子（0–15s）     一句话说清"这条解决什么"     ← 决定播放
② 铺垫（15–30s）    为什么这件事重要 / 我曾经踩过坑 ← 决定留存
③ 主体（30s–80%）   核心内容                       ← 决定完播
④ 结论（80–95%）    ⭐ 可直接抄的一页（带数字）      ← 决定收藏
⑤ 人格（95–100%）   ⭐ 一句"我"的话                 ← 决定涨粉率
⑥ 收尾              下期悬念（不提课程）            ← 决定追更
```

## 3.2 ⭐ 第 ⑤ 段「人格锚点」—— 这是新增的，也是最重要的

**为什么加**：涨粉率恒定 0.2%，**只有人格能改这个数**。

**格式**：一句话，三个类型之一

| 类型 | 句式 | 例 |
|---|---|---|
| **代价型** | "我……（付出了什么）才知道" | 「我第一次上保护站，用的是自己拿散扁带打的」 |
| **失败型** | "我犯过……" | 「我当时牛尾挂反了，锁门朝着岩壁」 |
| **改变型** | "我以前……后来我改了" | 「我以前两种结都用，现在只用一种」 |

**位置**：**放在结论之前或之后，不要放在开头**（开头要给钩子，不给自我介绍）

## 3.3 ⭐ 第 ④ 段「可抄的一页」—— 决定收藏率

**判定标准（过或不过）**：

```
□ 有没有绝对数字？（¥ / mm / 秒 / 条数）
□ 观众能不能截图直接拿去用？
□ 是不是在最后 1/4 的位置？
```

**反例**（全都不合格）：
```
❌ 「价格按你预算挑」
❌ 「选适合你的」
❌ 「注意安全」
```

**正例**：
```
✅ 「60m · 9.8–10.2mm · ¥600–1200」
✅ 「两个点都挂 / 锁门朝外 / 拧到底+回拉 / 牛尾不拧麻花」= 8 秒
```

# 五、⭐ 选题决策法（新）

## 5.1 选题时先问一句

> **"这件事，多少人正在花钱？"**

| 选题 | 谁在花钱 | 预测 |
|---|---|---|
| 快挂怎么选 | 要买快挂的人（买好几把） | 高 ✅ |
| 主锁怎么选 | 刚入门的人（第一件） | 高 ✅ |
| 保护器怎么选 | 要买保护器的人（一买一个） | 中 |
| 主绳怎么选 | 要买绳的人（买一条用三年） | 中低 |
| 攀岩简史 / 装备总览 | 没人正在花钱 | 低 ❌ |

## 5.2 选题分层

```
🔥 高播放层（做量）：正在花钱的装备 / 出事怎么办 / 争议话题
💰 高收藏层（做资产）：参数表 / 清单 / 价格对照
❤️ 高人格层（做粉）：我的失误 / 我的故事 / 我的改变
```

**一个系列里，三种都要有。别全做一种。**
