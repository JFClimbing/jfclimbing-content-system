## 使用原则

1. **脚本是骨架，不是逐字稿** —— 照着说会很僵，按结构用自己的话讲
2. **每条动作都有"为什么"** —— 理解了再执行，遇到情况能自己判断
3. **数据反馈优先** —— 脚本里给的预期值都是经验值，跑出来不一样就用你自己的数据
