# 标签规范（抖音 / 小红书 / 公众号）

> **建立于** 2026-09-18
> **为什么要有这份文件**：标签不是"锦上添花"，是平台**自动归类**和**搜索收录**的入口。
> 不带标签 = 平台不知道你是谁 = 只能靠自然完播碰运气。
> **从今往后，每一条内容的交付物都必须包含标签，不许写"有就挂"。**

---

## 一、底层逻辑：标签在干什么

```
用户刷到你的内容，平台要回答三个问题：
  ① 这是哪个领域？   → 靠标签（大词）
  ② 该推给谁？       → 靠标签（人群/场景词）
  ③ 有人搜的时候，能不能搜到？  → 靠标签 + 标题/正文里的关键词
```

**所以标签有三层，缺一层就漏一块流量。**

| 层 | 作用 | 攀岩赛道例子 |
|---|---|---|
| ① **领域大词** | 让平台把你归到「攀岩」这个大类，进大池子 | `#攀岩` `#攀岩装备` |
| ② **精准词** ⭐ | 吃**搜索流量** —— 用户真会输入的字 | `#攀岩保护器` `#龟龟` `#ATC` |
| ③ **人群 / 场景词** | 推给对的人，提高匹配度 | `#攀岩新手` `#户外运动` |

> ⚠️ **精准词比大词更值**。
> `#攀岩` 有几百亿播放，你挤不进前排；
> `#攀岩保护器` 池子小，但你排得进去 —— **小池子的高匹配 > 大池子的低匹配**。

## 二、各平台的数量与上限（已核实）

| 平台 | 硬上限 | 建议用几个 | 备注 |
|---|---|---|---|
| **抖音** | 无硬性数量上限 | **5 个** | 文案默认显示 55 字，可以点展开突破（上限约 1000 字符）。**有官方活动话题必挂** |
| **小红书** | **10 个** | **5 个** | ⚠️ 8 个以上会被判「主题不聚焦」，互动率反而**低 27%**。3–5 个是最优区 |
| **公众号** | **5 个话题标签**（硬上限） | **5 个** | ⭐ **历史文章也能补加** —— 可以用来盘活旧文 |
| **公众号图片消息** | 同公众号 | 5 个 | 图片最多 9 张、标题 ≤64 字、描述 ≤1000 字 |

### ⭐ 一个容易被忽略的动作

**公众号的历史文章可以补加话题标签。**

你号里有一大批原创内容，**逐篇补上话题标签 = 免费的二次曝光**
（话题标签会显示在文首，点进去是话题聚合页）。
不运营的号，这是性价比最高的动作 —— 花 10 分钟，给 20 篇旧文挂上话题。

## 三、六条铁律

```
① 每条必须带标签，不允许空标签
② 三层都要有：大词 + 精准词 + 人群词
③ 精准词优先于大词（小池子高匹配 > 大池子低匹配）
④ 标签必须和内容一致 —— 凑热门会被判「主题不聚焦」，反降权
⑤ 有官方活动话题，一定挂（如 #攀岩入门指南，有流量奖励）
⑥ 标签只写平台已有的、有搜索量的；生造词没人搜，等于没挂
```

## 四、使用模板（每个平台开工前对着填）

```
【领域大词】     #攀岩  #攀岩装备
【精准词】       #攀岩保护器        ← 这条内容的核心搜索词，必须有
【人群/场景词】  #攀岩新手  #攀岩教学
【活动话题】     #攀岩入门指南      ← 有就挂
```

## 六、自查清单（发之前过一遍）

```
□ 标签写了吗？（不许空）
□ 三层齐了吗？（大词 / 精准词 / 人群词）
□ 有搜索量吗？（生造词不算）
□ 和内容一致吗？（凑热门会降权）
□ 这个平台的数量对了吗？（抖音5 / 小红书5≤10 / 公众号5）
□ 有官方活动话题吗？挂了吗？
```
