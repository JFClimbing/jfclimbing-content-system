# 抖音粉丝群 · 前 7 天运营脚本

> **目标**：7 天内把"静默群"变成"**有人主动问课**"的群
> **成本**：零
> **前提**：不需要企业号、不需要资质、全程不违规

---

## 📌 先理解三件事（不理解就别照做）

### 1. 群的价值 = 你能不能持续提供「这里才有的东西」

只发广告的群，**三天就死**。群要活，必须有独占价值。

### 2. 前 7 天是「破冰期」—— 决定群的生死

群主前 7 天的发言比例应该**占 80%**。你不说话，群就是死的。

### 3. **不要一进群就卖课**

前 5 天给价值，第 6-7 天再试探。急着卖 = 人跑光。

---

# 第 0 天：开通 + 设置（约 30 分钟）

## 开通路径

```
抖音 App → 我 → 右上角菜单 → 创作者服务 → 粉丝群
（或：创作者中心 → 互动管理 → 粉丝群）
```

**个人号就能开，零成本。**

## 群名

```
骄峰 · 攀岩入门交流
```

> ⚠️ 不要叫「骄峰攀岩课程咨询」—— 一看就是卖课的，没人进。

## 群公告（直接复制）

```
欢迎来到「骄峰 · 攀岩入门交流」

这个群是干嘛的：
· 聊攀岩、聊装备、聊户外
· 有问题随时问，我看到会回
· 线下活动会在这里先发

三条规矩：
① 不发广告、不拉人、不发外链
② 不聊与技术无关的争议话题
③ 新手问题随便问，没有人会笑你

我每周三晚上 8 点会在群里答疑
```

## 主页引导

在抖音主页的「简介」里加一句：

```
攀岩装备/技术分享 · 有问题的进粉丝群
```

> ⚠️ **不要写微信号、不要写电话** —— 这是红线。

## 已有内容的置顶评论

去你**最近 3 条**内容下方，各置顶一条：

```
想系统学的可以进主页的粉丝群
有问题随时问，我看到会回
```

> 这一步是**冷启动的关键** —— 把你的存量流量导入群。

# 第 1 天：破冰（10 分钟）

**目标**：让第一批人开口说话。

## 发这条

```
大家好，我是骄峰 🧗

先自我介绍一下：
攀岩这几年一直在爬结组和技术路线，
现在主要在做攀岩装备和技术的科普。

想先认识一下大家 ——
你们第一次攀岩是在哪？

我先说：我第一次是在室内岩馆，
上去 3 米就下不来了，腿一直在抖 😂
```

## 为什么这样设计

| 设计 | 目的 |
|---|---|
| 自我介绍 | 让人认识你是谁 |
| **提问** | 给人一个**低门槛**的开口理由 |
| **自己先答** | 示范格式 + 暴露自己的"菜"，降低别人开口的心理门槛 |
| 用"第一次" | 每个人都有答案，**没人答不出来** |

## 预期

- 刚开始可能只有 2-3 个人回 —— **正常**
- **每一个回复你都要回**（这很重要，决定了别人敢不敢说话）

# 第 2 天：给价值（15 分钟）

**目标**：证明"进这个群有用"。

## 发这条

```
今天讲一个很多新手都会忽略的东西 ——

【绳尾结为什么必须打】

攀岩绳从保护器穿出来，末端一定要打一个结。
原因很简单：如果绳尾从保护器里滑出去，
保护者就抓不住绳了，这个时候人会直接落到地上。

尤其是绳长不够、或者下降的时候，
绳尾滑出去是真发生过的事故。

所以规矩是：
绳尾留 25cm 以上，打一个结。
不管什么情况，养成习惯。

（这一条你可以截图存着）
```

## 为什么这样设计

| 设计 | 目的 |
|---|---|
| 短（3-4 句） | 群里没人看长文 |
| **具体 + 保命** | 让人有"幸好看到了"的感觉 |
| "截图存着" | 制造**可保存**的价值 |
| 和他抖音内容呼应 | 群里给"抖音没细讲的" → 让进群有理由 |

## 关键

**不要发链接、不要发长图。** 就发文字。
群里发链接会让人觉得是广告。

---

# 第 3 天：互动 · 动作点评（30 分钟）

**目标**：从"看"变成"参与"。

## 发这条

```
今天想跟大家玩个互动 ——

如果你有自己攀岩的视频（随便拍的都行），
可以发到群里，我帮你看一下动作。

不管是新手还是老手都行，
我先看几个，挑最典型的说。

（没有视频的也可以发问题，一样回答）
```

## 为什么这样设计

| 设计 | 目的 |
|---|---|
| **动作点评** | 这是**最有价值的群内服务**，抖音评论区做不到 |
| 门槛低 | "随便拍的都行" |
| 也接受问题 | 兜底，防止没人发视频时冷场 |

## 如果没人发

**不要等。** 自己先发一个：

```
那我先发一个我自己的，当抛砖引玉 👇
（发一个你自己攀爬的片段）
```

群主先发 = 降低别人的心理压力。

## ⚠️ 点评时的注意事项

- **先夸一个真实的点**（不是硬夸，找一个真的做得好的细节）
- 再指出 1-2 个可以改的地方（不要一次说 10 个）
- 最后给一个**下次可以试的具体动作**

> 这条是**建立专业信任的关键**。你点评得准，大家就知道你确实懂。

# 第 4 天：让他看见"你这个人"（15 分钟）

**目标**：从"一个懂技术的人"变成"一个真实的人"。

## 发这条

```
今天不发干货，发个我自己的东西 ——

（发一段你自己在岩馆/户外攀爬的实拍片段，或者一张照片）

这是上周在 XX 岩馆爬的，
这条线路我掉了 6 次才过，
最后一次握点的姿势终于对了。

攀岩这个东西，进步全在那些"又掉下来了"的瞬间里。
```

## 为什么这样设计

| 设计 | 目的 |
|---|---|
| **不卖任何东西** | 建立"这个群不是广告群"的印象 |
| 真人实拍 | ← **这是图文给不了的东西**，也是你要做视频的原因 |
| 暴露失败（掉了 6 次） | 真实感 > 完美感，反而更让人信任 |
| 最后一句有观点 | 建立"你不只是会爬，还有想法" |

> 💡 **这一天非常重要。** 群友对你的信任，80% 来自"他们觉得你是个真实的人"，
> 而不是"你懂得多"。

---

# 第 5 天：制造节奏感（10 分钟）

**目标**：让群有"日程"，不是随手点进来的地方。

## 发这条

```
跟大家说个安排 ——

以后每周三晚上 8 点，我在群里答疑一小时。
攀岩技术、装备、训练，什么都能问。

第一个答疑就是下周三晚 8 点。
有问题可以先攒着，到时候一起问。
```

## 为什么这样设计

| 设计 | 目的 |
|---|---|
| **固定节奏** | 群有了"日程感"，人会记得回来 |
| 提前预告 | 制造期待，也让别人有"我到时候要问什么"的心理准备 |
| 不设门槛 | "什么都能问"降低参与门槛 |

> 📌 固定节奏是**群能不能长期活下去**的关键。
> 没有节奏的群，两周后就是死群。

---

# 第 6 天：第一次线上活动（60 分钟）

**目标**：验证群的活跃度，也让群友形成"这个群有活动"的记忆。

## 预告（当天下午发）

```
今晚 8 点答疑，别忘了 ⏰
有问题的直接在群里发，我一条条回。
```

## 到点开聊（20:00 准时发）

```
开始啦，有问题直接发 👇

如果没人开口，我先答一个大家都关心的：
"新手第一套装备到底买什么？"

（然后自己讲 5 分钟）
```

## 关键技巧

| 情况 | 怎么做 |
|---|---|
| 没人提问 | **自己先答一个高频问题**（绝对不要冷场等） |
| 有人提问 | 认真答，答完追问一句"这样清楚吗" |
| 没人理 | 也照常讲完 —— **群是可以只看不说的**，别因为没人互动就停 |

> ⚠️ **最重要的一条**：即使群里没人回应，你也要**按时开、按时讲完**。
> 沉默的围观者才是大多数。他们不说话，但都在看。

---

# 第 7 天：第一次轻转化试探（15 分钟）

**目标**：测试转化率 —— **但不要硬推**。

## 发这条

```
问一下大家 ——

如果周末组织一次线下体验，
3 小时，装备和保险全包，400 块，
你们有兴趣吗？

想去的在群里回复「1」，
我看人数够不够，够的话这周就安排。

（主要是想带大家真的上一次墙，
有些东西群里讲不清楚，得在现场。）
```

## 为什么这样设计

| 设计 | 目的 |
|---|---|
| **用"问一句"代替"卖"** | 问询 = 无压力，转化率反而更高 |
| 说清包含什么 | 装备 + 保险 = 降低决策成本 |
| **限额感**（"人数够不够"） | 自然的稀缺性，不是硬造 |
| 最后一句解释为什么线下 | 让"线下"这件事显得自然，不像推销 |

## ⚠️ 三条红线（这一条最容易出事）

```
❌ 不要在群里发微信号 / 二维码
❌ 不要让人"加我微信报名"
❌ 不要在评论区公开留联系方式
```

**正确的做法**：

```
报名 → 群里确认一下基本信息（人数、时间）→ 线下见面 → 现场自然加微信
```

> **加微信这一步放在"线下见面时"** ——
> 那是面对面行为，不涉及平台导流，而且质量最高（愿意花 400 块来的人）。

## 如果没人回复

**不要慌，也不要追着问。** 可能只是：
- 群还太小（前 7 天人数本来就少）
- 时机不对（周末可能很多人已经有安排）

**调整方式**：换个时间再问一次，或者先做一个**免费**的小活动（比如组织一次一起爬），
把"见面的习惯"先建立起来。

# 📊 只看三个指标

| 指标 | 怎么看 | 参考 |
|---|---|---|
| **群人数** | 每天涨多少 | 前 7 天能进 20-50 人就算成功 |
| **发言人数占比** | 有多少人说过话 | 前 7 天 10-20% 正常，别期望高 |
| **第 7 天活动报名数** | 想去的回复「1」的有几个 | 能到 3-6 人就说明转化成立 |

> ⚠️ **不要把"发言人数"当唯一指标。**
> 群里**沉默的人永远是大多数**，他们在看，不在说。
> 真正说明群健康的是：**你的内容有没有被"保存/截图/转发"**。

# 🔁 第 8 天之后：长期节奏

群活不活，看有没有**固定节奏**。建议：

| 频率 | 做什么 | 耗时 |
|---|---|---|
| **每天** | 群里说一句话（不用长） | 2 分钟 |
| **每周三晚 8 点** | 固定答疑 | 60 分钟 |
| **每周一次** | 动作点评 / 干货分享 | 20 分钟 |
| **每 2 周一次** | 线下活动（免费或收费） | 半天 |

> 一天 2 分钟，是**最低成本的"群还活着"信号**。
> 哪怕只发一句"今天去岩馆爬了一下午，累但爽" —— 也有用。

# 🗣 话术库

## 有人问"怎么报名"

```
先在这个群里报个名（几点、几个人），
我确认一下人数，够的话就安排。
具体细节我们在群里说就行。
```

**（不提微信）**

## 有人问"能不能加微信"

```
群里说就挺好，也方便别人一起看 👌
等你来上课了当面加～
```

## 有人发广告

```
不好意思，群里不发广告哈，这次先删了。
想交流的随时说话 👋
```

**（删掉，但态度友好。不要骂人，也不要装没看见）**

## 有人问很专业的问题，你也不确定

```
这个我不太确定，别乱教你 ——
我查一下 / 问问朋友，确认了回你。
```

> ⚠️ **这条比什么都重要。**
> 承认"不确定"不会让你显得不专业，**瞎答才会**。
> 尤其涉及安全的技术，宁可不答。

## 常见错误清单

```
□ 一进群就开始卖课          → 人跑光
□ 群里发长文 / 长图          → 没人看
□ 群里发外链                 → 像广告
□ 没人说话就放弃更新         → 群两周变死群
□ 留微信号 / 二维码          → 违规
□ 答疑时间不固定             → 群没有节奏感
□ 答不上来的问题硬答         → 失去信任
```
