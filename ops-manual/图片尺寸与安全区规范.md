# 图片尺寸与安全区规范

> 建档 2026-09-18 ｜ 来源：抖音图文竖版官方推荐比例 + 短视频封面安全区实践（framelab.cn 2026-09-14 更新等多来源交叉）
> **配套模板**：`content-lab/design-templates/安全区模板_3比4_1080x1440.png` · `安全区模板_9比16_1080x1920.png`

---

## 一、结论（先看这个）

| 用途 | 比例 | 像素 | 安全边距 |
|---|---|---|---|
| **抖音图文（我们全部内容）** | **3 : 4** ✅ | **1080 × 1440** | **四边各留 8%**（≈86 × 115 px） |
| 视频封面（暂不做） | 9 : 16 | 1080 × 1920 | 上 220 / 下 380 / 左右 65 px |

**理由**：3:4 是抖音图文竖版的官方推荐比例，**与小红书封面逻辑一致** ——
一套图能在抖音 + 小红书两边直接用，不用重做。

---

## 二、为什么 9:16 会把文字切掉

9:16（1080×1920）是**视频封面**的比例。图文里图会铺满全屏，然后：

```
┌──────────────┐  ← 顶部 220px：状态栏 + 作者信息
│   UI 遮挡     │
├──────────────┤
│              │
│   安全区      │  ← 只剩 1320px 高
│  （1320px）   │
│              │
├──────────────┤
│   UI 遮挡     │  ← 底部 380px：文案 + 点赞/评论/分享按钮 + 进度条
└──────────────┘
```

**上下合计吃掉 600px = 31%。**

文字越靠边，越容易被按钮压住 —— 这就是「边缘把文字切掉」的真正原因。

而 3:4 的图**不铺满全屏**，上下会留白，**按钮压在留白上，不压你的图**。

## 三、作图规则（三条，照做就不会出错）

```
① 画布：1080 × 1440（3:4）
② 四边各留 8% 不写字
   左右 86px，上下 115px
③ 关键信息放中间 2/3
```

### 具体到每一张

| 位置 | 放什么 |
|---|---|
| 上 8%（0–115px） | 空着，或纯色底 |
| 中上 1/3 | **标题 / 封面主视觉** ← 最容易被看到 |
| 中间 | 正文、图解主体 |
| 下 8%（1325–1440px） | 空着，或只放「峰」签名 |

### 字号底线

```
1080 宽度下，正文字号 不小于 40px
标题字号         不小于 72px
```

低对比度配色 = 等于没写。信息流里图只有几厘米见方。

---

## 四、导出参数

| 项 | 值 |
|---|---|
| 格式 | JPG 质量 85–90（或高质量 PNG） |
| 单张体积 | ≤ 500 KB（上传快、压缩少） |
| 短边 | ≥ 1080 px（低于 720px 几乎必然发糊） |
| 一组内比例 | **必须统一** —— 滑动时才连贯 |

---

## 五、执行约定

- **第 0 ~ 3 集**：已是 9:16，**不重做**（已发/已定时）
- **第 4 集起**：全部改 **3:4（1080×1440）**
- 作图时把 `安全区模板_3比4_1080x1440.png` 放在最底层当参考线，做完再删
- 一套图同时用于抖音 + 小红书（两边都是 3:4）

---

## 六、自查清单（每次导出前）

```
□ 画布是 1080 × 1440 吗？
□ 四边各留够 8% 了吗？有文字进红区吗？
□ 组内所有图比例一致吗？
□ 短边 ≥ 1080px 吗？
□ 标题字号 ≥ 72px 吗？
□ 单张 ≤ 500KB 吗？
```
