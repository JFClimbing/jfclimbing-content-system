# 工作室内容生产工作流（飞书多维表格版）

> 建立于 2026-10-02
> 参考：影视飓风等工业化视频团队的共性做法
> 规模：3 人工作室（编剧 / 拍摄剪辑 / 运营）
> 平台配比：**抖音 80% · 小红书 20%**

---

## 一、先解决一个关键问题：**标题什么时候定？**

你问的这个问题是整条流程里最容易出错的地方。答案是 —— **标题不是最后写的，是分两次。**

```
第一次（编剧，写脚本时）
   └─ 定「钩子」和「标题方向」
      理由：视频前 3 秒必须和标题呼应。
            如果标题承诺了 A，开头讲的是 B，从推荐流点进来的观众会立刻划走。

第二次（运营，成片后）
   └─ 根据实际画面 + 平台特性定稿
      · 抖音：钩子型（对抗划走）
      · 小红书：搜索型（20 字内，匹配搜索意图）
```

**所以表格里必须有三个字段**：

| 字段 | 谁填 | 什么时候 |
|---|---|---|
| `标题候选`（3 个） | 编剧 | 写脚本时 |
| `钩子（前 3 秒）` | 编剧 | 写脚本时 |
| `标题_定稿` / `标签_定稿` | 运营 | 成片后 |

> ⚠️ **反模式**：编剧写完脚本不管标题，运营拿到成片硬憋一个 ——
> 结果就是"标题和内容对不上"，完播率低，也不涨粉。

## 二、流程总览（8 个状态）

```
① 选题
   编剧提 → 制片/运营确认
        ↓
② 写脚本          编剧
   交付：脚本文档（含标题候选 + 钩子 + 素材需求）
        ↓
③ 脚本审         制片 + 拍摄 + 运营 一起看
   交付：脚本定稿（评论里 @ 相关人）
        ↓
④ 拍摄            拍摄
   交付：素材上传 + 素材清单打勾
        ↓
⑤ 剪辑            拍摄
   交付：成片链接
        ↓
⑥ 待发布          运营
   交付：标题定稿 + 简介 + 标签 + 排期
        ↓
⑦ 已发布          运营
        ↓
⑧ 已复盘          运营 + 编剧
   交付：数据 + 一句话结论（回流到选题库）
```

**关键交接物（缺一个就不许往下走）：**

| 从 → 到 | 必须交付 |
|---|---|
| 编剧 → 拍摄 | **脚本 + 素材清单**（不然拍摄不知道拍什么） |
| 拍摄 → 运营 | **成片 + 素材清单完成率**（哪几个镜头没拍到要标注） |
| 运营 → 复盘 | **标题/标签定稿 + 链接**（不然不知道数据对应哪条） |

## 四、视图建议（两个人看同一张表的不同面）

| 视图名 | 筛选 | 给谁看 |
|---|---|---|
| **编剧视角** | 状态 ∈ {选题, 写脚本} | 编剧 |
| **拍摄待办** | 状态 ∈ {脚本审, 拍摄, 剪辑} | 拍摄 |
| **运营待办** | 状态 = 待发布 | 运营 |
| **本周排期** | 计划发布 ∈ 本周 | 全员 |
| **未复盘** | 状态 = 已发布 | 运营 |
| **数据看板** | 按平台分组统计 | 制片 |

> 💡 **多维表格最大的价值就是"同一份数据，每人看自己那一屏"** ——
> 不用开会同步进度，看板自己会说话。

## 五、参考影视飓风这类工业化团队的 5 个习惯

> ⚠️ 以下是从公开分享中提炼的**共性做法**，不是他们的内部文档。

| # | 习惯 | 怎么落到你的表里 |
|---|---|---|
| 1 | **选题会前置** | 选题库先囤 10-20 条，不要"今天拍什么"现想 |
| 2 | **脚本标准化** | 固定模板：钩子 → 主体(3-4点) → 收尾 + 素材清单 |
| 3 | **拍前定分镜** | 用「素材清单」表，拍之前列清要拍什么 |
| 4 | **看片会** | 成片必过审（状态 ⑥ 待发布 之前人工卡一道） |
| 5 | **数据回流** | 复盘结论写回主表 → 下次选题时参考 |

## 六、抖音 vs 小红书 在流程里的差异

| 环节 | 抖音 | 小红书 |
|---|---|---|
| **配比** | 80% | 20% |
| **标题长度** | 长（前 55 字关键） | **≤ 20 字** |
| **标题风格** | 钩子型（对抗划走） | 搜索型（匹配搜索意图） |
| **标签数量** | 5 个 | 5-10 个 |
| **封面** | 图解 + 大字 | **实拍照片，图上字 ≤ 5 个** |
| **发布后重点看** | 完播率 / 划走率 | **分享率 / 收藏率** |

> 📌 **同一条内容两个平台可以复用素材，但标题、简介、标签、封面必须分开做。**
> 在表里体现为：平台字段 + 两套"定稿"字段（或者拆成两行）。

## 七、最小可用版（如果嫌复杂）

**先只建表 1，跑两周。**

表 1 里必须有这三个字段：
```
□ 状态（8 个状态）
□ 标题候选（编剧填）
□ 标题/标签定稿（运营填）
```

**跑顺了再加表 2（素材清单）和表 3（数据记录）。**

> ⚠️ **不要一上来就搭全套。** 三个人还没形成习惯时，复杂的表会被放弃。
