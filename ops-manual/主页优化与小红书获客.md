## 一、主页优化（诊断：视觉三代混排）

### 真正的问题不在简介，在**作品封面的视觉一致性**

| 代 | 风格 | 例子 |
|---|---|---|
| 第一代 | 绿底 + 实物照片 + 文字压上去（最乱） | 追踪法八字结、双套结、渔人结 |
| 第二代 | 黑底 +「攀岩教学」白字 | 三种抓结、下降器掉落、绳结收官 |
| 第三代 | **橄榄绿 + 手写体 + 干净版式（最好）** | 主锁篇、主绳篇 |

主页观感 = 三代混排 =「这个人没有体系」

### 改的优先级

| 优先级 | 动作 | 耗时 |
|---|---|---|
| 🔥 1 | **背景图换掉** —— 现在是夜景攀爬，暗。换成白天、明亮、能看清动作的照片 | 5 分钟 |
| 🔥 2 | **置顶 3 条**：主锁篇 + 主绳篇 + 绳结收官 | 2 分钟 |
| ⭐ 3 | 改**前 6 条**封面（首屏可见范围），统一成橄榄绿 | 30 分钟 |
| ⭐ 4 | 其余老封面不动，让它慢慢沉下去 | 0 |

> **不用全改。** 首屏 6-9 条决定第一印象。**从现在起新内容一律第三代风格**，一个月后自然统一。

## 二、小红书获客

### 为什么小红书更适合获客

| | 抖音 | 小红书 |
|---|---|---|
| 流量逻辑 | 推荐（刷到） | **搜索 + 推荐** |
| 用户意图 | 泛、随机 | **明确**（在搜"攀岩课""阳朔攀岩"） |
| 内容寿命 | 几天 | **几个月到几年** |
| 适合 | 拉新 | **精准获客** |

**小红书的搜索用户是带着"我要去/我要学"的意图来的 —— 离钱最近。**

### 内容侧：做「能被搜到」的三类内容

**① 本地化（吃地域搜索）** ⭐ 最重要
```
· 阳朔攀岩攻略：新手去哪面墙 / 多少钱 / 怎么去
· 阳朔攀岩一个月多少钱（住宿 + 装备 + 课）
· 湖南周边攀岩地合集
```

**② 入口型（吃"怎么开始"搜索）**
```
· 第一次攀岩要花多少钱
· 新手攀岩怎么开始（零基础版）
· 攀岩体验课值不值
```

**③ 决策型（吃"买什么"搜索）**
```
· 攀岩新手先买这 3 件（抖音那条的照片版）
· 主绳和辅绳怎么选
```

### 发布时的三个动作
```
□ 加「阳朔」地域定位
□ 封面用真实照片，0 文字
□ 标签带地域词：#阳朔 #阳朔攀岩 #攀岩新手 #户外运动
```

### 承接侧：和抖音同一套原则

| ❌ 不要 | ✅ 要 |
|---|---|
| 简介留微信号 | **私信承接**（用户主动来问） |
| 评论发联系方式 | 评论区认真回复（**别人也看得到**） |
| "扫码报名" | "想了解的可以私信我" |

**小红书的评论区是黄金位置** —— 有人问"在哪学"，你认真回，
其他 100 个看到的人也在建立信任。**这是抖音做不到的。**

### 你的稀缺资源：「阳朔」身份

全国想攀岩的人里，能去阳朔的是少数，但**想去的人极多**。
持续做「阳朔攀岩」内容 → "阳朔攀岩"的搜索量就是你的自然客流。

**同时喂两条线**：内容数据（搜索长尾）+ 线下获客（来阳朔的人需要教练）
