# 电脑 ⇄ 手机 通路（让手机借用电脑的梯子）

> **建立于** 2026-09-18
> **目标**：手机 iSH 里的命令（curl / yt-dlp）→ 走**电脑上的 VPN** → 访问 YouTube
> **前提**：电脑和手机连**同一个 Wi-Fi**；电脑上梯子已开

---

## 为什么需要这个

手机这边的网络**实测连不上 YouTube**（连 Invidious / Piped / r.jina.ai 等免费镜像也全被封）。
但你的电脑能翻墙 —— 所以只要**把手机的流量借道电脑**就行。

iSH 里的 curl / yt-dlp 都支持 `--proxy` 参数，所以只需要把电脑上的代理**开放到局域网**。

---

## 方案 A：梯子软件自带「允许局域网连接」⭐ 最省事

大多数梯子客户端都有这个开关：

| 软件 | 在哪里开 | 常见端口 |
|---|---|---|
| **Clash / ClashX / Clash Verge / Mihomo** | 「允许局域网连接 / Allow LAN」 | **7890** |
| **V2RayN（Windows）** | 参数设置 → 允许来自局域网的连接 | **10809** |
| **Surge / Shadowrocket / Stash** | Allow LAN | 看设置 |
| **sing-box** | `"listen": "0.0.0.0"` | 看配置 |

**步骤**：

```
1. 电脑上打开这个开关
2. 查电脑的局域网 IP：
     Mac      →  ipconfig getifaddr en0
     Windows  →  ipconfig   （看"IPv4 地址"）
   例如：192.168.31.100
3. 手机上测一下
```

**手机端验证命令**：

```bash
curl -x http://192.168.31.100:7890 -sI https://www.youtube.com
```

看到 `HTTP/2 200` 就通了。

---

## 方案 B：用我写的脚本（梯子只监听 127.0.0.1 时）

有些梯子默认**只允许本机**访问。用一个单文件脚本把它转出去：

**脚本位置**：`/root/bin/lan_proxy.py`（已在本机自测通过，无第三方依赖）

**拷到你电脑上，跑**：

```bash
python3 lan_proxy.py 8899 --upstream 127.0.0.1:7890
#                                ↑ 换成你梯子的 http 端口
```

脚本会打印出手机该用的地址，例如 `http://192.168.31.100:8899`。

**如果梯子开了 TUN / 增强模式**（全局路由），可以省掉 upstream：

```bash
python3 lan_proxy.py 8899
```

**手机端验证**：

```bash
curl -x http://192.168.31.100:8899 -sI https://www.youtube.com
```

## 方案 C：SSH 动态转发（Mac 零安装）

Mac 自带 SSH 服务，不用装任何东西。

```
1. Mac：系统设置 → 通用 → 共享 → 打开「远程登录」
2. 手机（iSH）里跑：
     ssh -D 1080 -N 你的Mac用户名@192.168.31.100
   （回车输密码；-N 表示只做端口转发不执行命令；
     需要留在前台，可以配合 minis://open_terminal 开个终端挂着）
3. 另开一个 shell 用 SOCKS5：
```

```bash
curl --socks5-hostname 127.0.0.1:1080 -sI https://www.youtube.com
yt-dlp --proxy socks5://127.0.0.1:1080 "<YouTube 链接>"
```

## 打通之后能干什么

### ① 直接拿元数据

```bash
yt-dlp --proxy http://<电脑IP>:<端口> --skip-download --print "%(title)s | %(duration)s | %(view_count)s" "<频道链接>"
```

### ② 直接拿字幕（**比语音转文字快得多**）⭐

```bash
yt-dlp --proxy http://<电脑IP>:<端口> --skip-download \
       --write-auto-subs --sub-langs "en.*" --convert-subs srt "<视频链接>"
```

→ **几秒钟拿到全片讲稿**，不用下载视频、不用转录。

### ③ 拿不到字幕时，用我写的转录链路

```bash
python3 /root/bin/yt_grab.py "<视频URL>" --lang en-US --tag "HardIsEasy_某集"
```

输出到 `/var/minis/workspace/`：
- `<tag>.txt` 纯讲稿
- `<tag>.ts.txt` 带时间戳（**能分析他的节奏：哪一段在讲话、哪一段留白**）

## 📊 顺手做出的一个实测发现

用转录链路跑 Hard Is Easy 的《Belay Masterclass Ep.1》（05:02），逐 30 秒统计说话量：

```

00:30    0 词                ← 整整 30 秒不说话
01:00   21 词  ███          ← 01:01 才正式开口
01:30   39 词  ██████
02:00   61 词  ██████████
02:30   66 词  ███████████
03:00   64 词  ██████████
03:30   82 词  █████████████
04:00   55 词  █████████
04:30   83 词  █████████████
```

**开场前 60 秒一共只说了 10 个词**（"I cannot reach it from here / you got me Carter"）——
画面自己在讲故事，旁白到最后才进来。

> 这就是"电影感"的真实做法：**不是画面多美，是敢不讲话。**
