---

# 一、为什么拆（你判断对了，这是依据）

| 依据 | 说明 |
|---|---|
| ⭐ **你自己的数据** | 小红书「每图字数 ↔ 观看量 **ρ = −0.636**」→ **信息密度越低越好** |
| **抖音推流机制** | 一条视频一个钩子。**4 条 = 4 次进流量池；1 条拼盘 = 1 次** |
| **转发需要"一个理由"** | 塞 3 件事 → 不知道转发哪件。3 条独立 → **3 个转发理由** |
| **数据学习** | 3 条 = 3 组数据 → 知道**哪种"蠢"最能共鸣** |

## ⚠️ 拆开的前提：3 条**形式必须不同**

```
❌ 三条都是"我干了 X，哈哈哈哈"  →  把一条烂视频变成三条烂视频
✅ 三条三种喜剧机制              →  才是真拆开
```

# 🎬 E2｜我从保护员前面走过去了

**形式**：情景重演 + 对手戏 ｜ **时长 12–15 秒** ｜ **需要 1 个人配合**（没人也能拍，见下）

## 笑点在哪

```
笑点 = "慢悠悠" × "被瞪"
她走过去的时候完全没意识到 → 保护员扭头看她 → 她一脸茫然
```

**⚠️ 关键：走过去必须"慢"，慢到有点欠揍。**
快走过去是"没注意"；**慢悠悠走过去才是笑点**。

---

## 逐镜表

| 镜 | 时间 | 画面 | 机位 | 声音 |
|---|---|---|---|---|
| 1 | 0:00–0:03 | **她慢悠悠从保护员正前方横穿**（侧拍，全身） | 三脚架，侧面 | 只有脚步声 |
| 2 | 0:03–0:05 | **保护员扭头看她**（特写脸） | 三脚架，保护员前方 | ⭐ **「叮」音效** |
| 3 | 0:05–0:07 | **她回头看**，一脸"怎么了？" | 三脚架，正面 | 无 |
| 4 | 0:07–0:15 | 她对着镜头说落点 | 三脚架，半身 | 口播 |

## 口播（只有最后一句）

**第 4 镜**：
> 「我当时不知道——//
> 我从保护员前面走过去，/ **挡的是他的视线**。//
> 上面那个人要是正好掉了，/ 就那一秒钟，/ 他看不见。//
> 现在我走到那边，/ **都会绕到后面**。」

---

## ⭐ 没人配合怎么办（一个人也能拍）

```
① 三脚架架在侧面，拍你自己慢悠悠走过去
② 把三脚架搬到"保护员"的位置（贴墙，约 1.5 米高），
   再拍一次你自己横穿过去 —— 这次是"保护员视角"
③ 回来拍你自己回头看镜头
④ 剪辑时：镜头2 用「保护员视角」那一版 + 加一个「视线」音效
```

**"被瞪"这个镜头缺失 → 用音效补**：
```
保护员视角 + 画面轻微推近 + 「叮」 + 一秒黑屏
← 观众自己会脑补"有人在瞪他"
```

## 音效 / 字幕

```
镜 2： 「叮」 或 抖音热门"目光"音效
镜 4： 口播时字幕打大字：挡的是他的视线
```

---

## 标题（3 选 1）

```
A. 我从保护员前面走过去了
B. 第一次去野攀，我被人瞪了一眼
C. 这一步走错，我到现在还记得
```

**推 A** —— 主语是"我"，不是"你"，自嘲感对了。

## 封面

```
主画面：镜 2（保护员视角看你横穿）或者镜 3（你回头那一下）
小字：岩场蠢事 ①
```

## ⚠️ 检查清单

- [ ] 你走过去是"**慢悠悠**"的吗？（快了就没笑点）
- [ ] 有没有拍到"回头看"那一下？
- [ ] 结尾是「绕到后面」（我怎么做），**不是**「大家要注意」（你该怎么做）？
- [ ] 全片没出现"规矩""礼仪"这种词吧？

# 🎬 E3｜挂着绳的线，我抬脚就要上

**形式**：定格 + 刹车音效 ｜ **时长 10–14 秒** ｜ **不需要人**

## 笑点在哪

```
笑点 = "抬脚要上" × "突然刹车" × "慢慢把脚收回来"
喜剧节奏靠「定格」和「音效」—— 不靠台词
```

---

## 逐镜表

| 镜 | 时间 | 画面 | 机位 | 声音 |
|---|---|---|---|---|
| 1 | 0:00–0:03 | 她走向一条线，抬头看 | 三脚架，侧后方 | 脚步 |
| 2 | 0:03–0:05 | **抬脚，要踩上去** | 同上 | 无 |
| 3 | 0:05–0:06 | ⭐ **定格 0.6 秒**（画面冻住） | 同上 | ⭐ **「吱——」刹车音效** |
| 4 | 0:06–0:09 | **慢慢把脚收回来**（特写脚） | 三脚架，低机位 | 无 |
| 5 | 0:09–0:14 | 对着镜头说落点 + 耸肩 | 三脚架，半身 | 口播 |

**⭐ 第 3 镜是全条的灵魂**：
```
画面定格 + 刹车音效 + 屏幕轻微抖一下
← 这三样加起来 = 抖音观众秒懂的"哦哟"时刻
```

---

## 口播（第 5 镜）

> 「我看到一条线，上面挂着绳。//
> 想都没想，抬脚就要上。//
> 后来才知道——//
> **那根绳说明已经有人在爬了。**//
> 现在我看到绳，/ **第一件事是看绳，不是看线**。」

---

## 音效 / 字幕

```
镜 3： 「吱——」刹车 或 「咻」倒吸声
镜 5： 字幕大字：挂着的绳 = 有人在爬
```

## 标题（3 选 1）

```
A. 看到挂着绳的线，我抬脚就要上
B. 我差点抢了别人的线
C. 那根绳，我没看懂
```

**推 A** —— 动作画面感最强。

## 封面

```
主画面：镜 3 的定格帧（脚抬在半空）+ 加一个"❌"或者"刹车"贴纸
小字：岩场蠢事 ②
```

## ⚠️ 检查清单

- [ ] 定格够不够"突然"？（慢慢停就没笑点了）
- [ ] 刹车音效卡在定格的那一帧上了吗？
- [ ] 有没有"把脚收回来"的特写？（**这是第二个笑点**）
- [ ] 结尾是「我看绳」（我怎么做），不是「要先问」（你该怎么做）？

# 🎬 E4｜我在石头上留了个镁粉块

**形式**：安静 + 反转 ｜ **时长 14–18 秒** ｜ **不需要人**

## 这条和 E2/E3 不同

```
E2 = 社死（被人看见）
E3 = 尴尬（差点出事）
E4 = 没人看见，但你还是回去捡了     ← ⭐ 这条不搞笑，它"有点暖"
```

**三条要有不同的调子**，不然就成三胞胎了。**E4 是全季的收尾，情绪落到"这人可以"。**

---

## 逐镜表

| 镜 | 时间 | 画面 | 机位 | 声音 |
|---|---|---|---|---|
| 1 | 0:00–0:04 | 她背起包，**要走**（背影） | 三脚架，全景 | 环境声 |
| 2 | 0:04–0:07 | **停住**，回头看地上 | 三脚架，侧后方 | ⭐ **音乐断一下** |
| 3 | 0:07–0:10 | **地上镁粉块特写**（她自己留下的） | 手持，凑近 | 无 |
| 4 | 0:10–0:14 | **弯腰捡起来**，塞进包 | 三脚架 | 无 |
| 5 | 0:14–0:18 | 对着镜头说落点 | 三脚架，半身 | 口播 |

**⭐ 第 2 镜的"停住"是这条的钩子** —— 比捡起来更重要。
**观众会想"她看到什么了"**。

---

## 口播（第 5 镜）

> 「走的时候，我在石头上发现了这个。//
> 一小块镁粉——/ 我自己掉的，/ 当时根本没感觉。//
> 岩场不是景区，/ **没人来打扫**。//
> 你留下的东西，/ 会在那儿待很久。//
> 现在我走之前，/ **会回头转一圈**。」

## 音效

```
前 6 秒：可以有一点点很轻的环境音/BGM（这条允许）
镜 2 停住：音乐"断"一下（留白）
镜 4 捡起来：一声很轻的"哒"
镜 5 口播：不要 BGM，直接说话
```

> E2/E3 是**全场无 BGM**，E4 可以**有一点** —— 这就是"三条不同"的地方。

## 标题（3 选 1）

```
A. 我在石头上留了个镁粉块
B. 走之前我回头看了一眼
C. 这件小事，岩场里没人会说你
```

**推 B** —— 不暴露"是什么"，只给"她回头了" → 制造好奇。

## 封面

```
主画面：镜 3（地上镁粉块特写）
小字：岩场蠢事 ③
```

## ⚠️ 检查清单

- [ ] "停住"那一下有没有拍？（这是钩子）
- [ ] 音乐在停住时有没有"断"？
- [ ] 捡起来那一下拍清楚了吗？（**不用拍得漂亮，要拍得自然**）
- [ ] 结尾是「回头转一圈」（我怎么做），不是「大家要带走垃圾」？
