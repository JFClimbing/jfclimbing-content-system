# 三平台差异化发布规范 v1

> 建立于 2026-09-23 ｜ 依据：三平台实测数据（抖音 20 条 / 小红书 54 篇 / 公众号 7 条）
> **适用**：从第 6 集（牛尾）起，每一集都按本规范产出三个平台版本。

---

## 0. 为什么必须分开做（不是"同一套内容发三遍"）

| | 抖音 | 小红书 | 公众号 |
|---|---|---|---|
| **粉丝** | 148 | **448** | **670** |
| **流量结构** | 推荐（算法分发） | 搜索 + 推荐 | **推荐 86.3% / 订阅仅 3.4%** |
| **主行为** | 划走（划走率是唯一先行指标 ρ=−0.50） | 收藏（收藏率 2.6–3.0%） | **转发（分享率 4–7%，是抖音的 40 倍）** |
| **长尾** | T+7 后停涨 | 24h 增量 ≤4，几乎无长尾 | **老文章持续复推数月（08-11 那批至今占 42% 阅读）** |
| **靠什么涨粉** | 人设 / 连载 | **主页访客率** | 文章内页关注按钮（95.5%） |
| **涨粉转化** | 0.18% | 0.90% | 1.2% |
| **形态** | 图文 8 张 3:4 | 图文（照片优先） | 贴图或文章，都可以 |

**结论：三个平台要用三套标题、三套封面、三套 CTA。**

## 1. 🔥 小红书专章（当前最高优先级）

### 1.1 瓶颈诊断（一句话）

> **小红书的问题不"没人看"，是"没人想认识你"。**

```
曝光 9,722 → 观看 1,561（封面点击率 17.3% —— 健康 ✅）
                 ↓  只剩 5.3%  ⚠️ 这就是瓶颈
             主页访客 82
                 ↓  17%  —— 这一环很好 ✅
             新增关注 14
```

**主页访客的转化率 17% 是健康的。问题在"想不想点进去看这个人"。**
→ 主页访客率提到 10%，涨粉速度**翻倍**，到 1,000 的时间从 2027-09 **砍到 2027-04 左右**。

### 1.2 根因：内容是「工具书」，不是「人」

现有 CTA 三件套（全系列统一）：

```
把这条收藏一下，进新岩馆之前翻出来看一眼；
身边刚办卡的攀岩朋友，转给他。
你们岩馆允许用液体镁粉吗？评论区说说。
```

**这套 CTA 完全正确——但它服务的是"收藏"和"转发"，不服务"关注"。**
观众拿到答案 → 收藏 → 走。**他没有任何理由想知道作者是谁。**

### 1.3 六条改动（按杠杆从高到低）

#### ① 🔥 结尾钩子：从「合集」改成「人」（最高杠杆）

**改写公式**：

```
【身份锚点】+【一个具体代价/数字】+【下一集的悬念】
```

**逐集改写示例**：

| 集 | 现在的结尾 | 改成 |
|---|---|---|
| 牛尾 | 「把这条收藏一下…转给他。你现在用的是环式还是可调式？」 | 「我是骄峰，在阳朔爬了 5 年。**我第一根牛尾是自己拿散扁带打的，直到有人告诉我打结后强度只剩一半**。下一集讲牛尾怎么选——包括我踩过的那个坑。关注这个合集，11 集讲完装备这件事。」 |
| 粉袋 | 「把这条收藏一下…你们岩馆允许用液体镁粉吗？」 | 「我在阳朔的岩馆被前台叫下来过一次，就因为液体镁粉。所以这一集我专门去查了各馆的规定。**下一集是这个合集的收官：装备到底按什么顺序买**——这也是最多人问我的问题。」 |
| 头盔 | 「收藏一下…」 | 「头盔是我唯一一次**真的被砸到**才重视的装备（不是砸到头，是砸到肩膀）。下一集讲安全带。」 |

**关键：把「代价」写出来。** 读者不在乎"你懂"，在乎"你付过什么学费"。

#### ② 正文固定「个人签名行」（每篇都要有）

小红书正文比抖音长，是唯一能写"人"的地方。放在**正文最末**：

```
📍 骄峰 · 常驻阳朔 · 从徒步到攀岩 5 年
📖 《攀岩装备基础篇》第 N / 11 集（合集在主页）
💬 新手问题评论区问，我看到就回
```

#### ③ 封面：从「手写长标题」改成「真实照片 + ≤8 字短标题」

**数据依据**（`rubric_notes-xhs.md` 实测）：每图字数与观看秩相关 **−0.636**（最强负向信号）；手绘图解封面**一律封顶 2 分**。
而她的历史爆款全是照片（9 万 / 4 万 / 8,097）。

→ **封面别放大段文字。用一张真实攀岩/装备照片 + 一行短句。**
→ 测量指标：创作中心「封面点击率」（现在 **17.3%**）。目标 **≥22%**。

#### ④ 系列显性编号「N / 11」

现在封面只有"第 X 集"，**没有总数**，观众不知道还有多少。
→ 封面或正文加「第 N/11 集」，制造"追更"。

#### ⑤ 主页改造（这一环已经 17%，只做一致性，不大动）

- 置顶三条：① 第 0 集（保护链总览）② 播放最高的一条 ③ 最人设的一条
- 简介加一句「新手问题直接问，我看到就回」（她抖音简介里已经有，小红书没有）

#### ⑥ 发布时间：统一到 19:30–21:00

现在小红书是 08:30 / 10:30 / 12:30 / 19:30 混着发。
户外人群活跃时段是晚 8–11 点。→ 统一到 **19:30–21:00**（待验证，先用 2 周对比）

### 1.4 ⭐ 本周就能做的两个 A/B 测试

| # | 假设 | 测什么 | 现在 | 目标 |
|---|---|---|---|---|
| **H-X1** | 加"人"的结尾钩子 → 主页访客率上升 | 创作中心「主页访客」 | 5.3% | **≥8%** |
| **H-X2** | 照片封面 > 手写封面 → 点击率上升 | 创作中心「封面点击率」 | 17.3% | **≥22%** |

**执行方式**：接下来的 09-24 牛尾 / 09-25 头盔 / 09-26 安全带 **三条都按新规范发**，
跟前面 09-22 的快挂 / 保护器 / 第 0 集（老规范）做对比。

### 1.5 小红书禁忌（别做）

- ❌ 别把抖音的 8 张图解原样搬过去（每图 75–110 字 = 严重超标）
- ❌ 别指望长尾（存量老笔记 24h 增量 ≤4，只有新发才动）
- ❌ 别指望靠标题字数堆关键词（搜一搜在小红书占比低，且内容窄众）

## 2. 抖音章

### 现状

- 播放能跑（快挂 5,329 @T+24h），但**涨粉效率极低：8,686 播放 → 16 粉 = 0.18%**
- 划走率是**唯一站得住的先行指标**（ρ = −0.50）→ **每集必看划走率**
- 长尾：T+7 后基本停涨 → **发布后 24h 决定 60–68%，T+3 决定 ~90%**

### 改动

| # | 动作 | 理由 |
|---|---|---|
| 1 | **保持图文线不变**（它是搜索资产） | 主锁/快挂证明图文能跑 5,000+ |
| 2 | ⭐ **另起短视频人设线** | 涨粉靠人设，图文做不到（见 `scripts/长视频线_对标Links_脚本方案.md`） |
| 3 | **结论页三项自检**（每集必过） | ① 结论唯一吗？② 有数字吗？③ 是倒数第 2 张吗？<br>保护器就是因为零数字，收藏率跌到 0.24% |
| 4 | **画幅统一 3:4（1080×1440）** | 快挂是首条 3:4，划走率 40.83% 为全系列最低；保护器是 9:16，47.29% |
| 5 | **8 张以内，不要有重复页** | 保护器第 6/7 张重复 → 平均浏览图掉到 2.7 |
| 6 | **标题：禁用纯装备名** | 新内容验证：保姆级 8,686 > 说明型 3,360 > 避坑 2,970（避坑型不再有优势） |

## 3. 公众号章

### 现状

- **推荐 86.3% / 订阅 3.4%** → 粉丝数几乎不影响流量，重点是**能不能进推荐池**
- **主行为是转发**（分享率 4–7.2%，是抖音的 40 倍）
- 收藏几乎为零 → **别再喊"收藏"**
- ⭐ **绳结/技术类是长尾引擎**（08-11 那批占近 7 日阅读的 42%）

### 改动

| # | 动作 | 理由 |
|---|---|---|
| 1 | ✅ **继续发贴图**（不是死路，已证伪） | 快挂（贴图）近 7 日 245 > 主锁（文章）224 |
| 2 | ⭐ **CTA 改成引导转发，不引导收藏** | 收藏几乎为零，分享率 4–7% |
| 3 | ⭐ **提到 1 条/天** | 推荐池曝光翻倍 |
| 4 | ⭐ **把抖音的绳结合集整体搬过来** | 那才是长尾引擎（近 7 日 42% 阅读来自 08-11 那批） |
| 5 | **标题与抖音/小红书统一** | 现在「那根保护草」vs「那根保命绳」，不统一 |
| 6 | **不用做 SEO** | 搜一搜只占 1.3% |

## 4. 每集产出流程（从这一集起执行）

### 4.1 一集 = 四个产物

```
scripts/第NN集_<主题>.md          ← 主脚本（内容源，只写一次）
    │
    ├─→ 抖音版：8 张图 3:4 + 标题（避坑/保姆级，不带纯装备名）+ 结论页三项自检
    ├─→ 小红书版：照片封面 + ≤8 字标题 + 个人签名行 + "人"的结尾钩子 + 晚 8 点发
    └─→ 公众号版：贴图/文章 + 引导转发 + 与另两平台标题统一
```

### 4.2 三个平台的具体差异表（每集填一遍）

| 项 | 抖音 | 小红书 | 公众号 |
|---|---|---|---|
| **标题** | 避坑 / 保姆级 / 场景型 | 同上，但更短、更口语 | 与抖音一致（用于统一心智） |
| **封面** | 手写大字 + 实物照片（现状 OK） | ⭐ **真实照片 + ≤8 字短标题** | 同抖音 |
| **正文 CTA** | 收藏 + 评论提问 | ⭐ **"人"的结尾钩子 + 个人签名行** | ⭐ **引导转发** |
| **张数** | 8 张 3:4 | 8 张 | 8 张 |
| **发布时间** | 19:30 | ⭐ 19:30–21:00 | 1 条/天，不定时 |
| **必看指标** | **划走率** | **主页访客率 + 封面点击率** | **分享率 + 是否进推荐池** |

### 4.3 发布后 3 天必查（三个平台各自的先行指标）

| 平台 | 指标 | 达标线 | 现在 |
|---|---|---|---|
| 抖音 | 划走率 | **< 47%** | 快挂 40.83% ✅ / 保护器 47.29% ⚠️ |
| 小红书 | **主页访客率** | **≥ 8%** | **5.3%** ❌ |
| 小红书 | 封面点击率 | ≥ 22% | 17.3% ⚠️ |
| 公众号 | 分享率 | ≥ 4% | 主锁 7.16% ✅ |
