# 一、先看结论：哪些能一次拍完

| 条 | 能不能一次拍完 | 卡在哪 |
|---|---|---|
| **1 第一次去野攀** | ✅ **完全能** | 需要一条完整的顶绳线（上得去、降得下来） |
| **2 五个礼节** | ⚠️ **大部分能** | 需要**第二个人**配合（3 个情景演绎镜头） |
| **3 我搭过最烂的保护站** | ✅ **能** | 需要**上顶部**（顶绳上去 或 绕路走上去） |
| **4 我为什么只用一种结** | ✅ **完全能** | 崖底就能拍，不需要爬 |
| **5 保护最容易犯的错** | ⚠️ **需要第二个人** | 有个人在爬，你才能拍"保护员"的镜头 |
| **6 拆除，我第一次手是抖的** | ✅ **能** | 需要**上顶部**（跟第 3 条同一次上去） |

**关键结论：**

```
✅ 不需要人配合，只需要"上顶部"的：第 1、3、4、6 条  → 一次全能拍
⚠️ 需要"第二个人"的：第 2、5 条                       → 最好约个岩友
```

**→ 如果约得到人，一次拍完 6 条。**
**→ 如果约不到，先拍 1/3/4/6 这 4 条，第 2/5 条等有人再说。**

# 二、⭐ 一次拍摄的流程设计

**核心思路**：**别按"条"拍，按"C 位"拍。**

同一个位置的所有镜头一次拍完，省掉来回折腾。

```
① 崖底（不爬）        → 出镜讲 + 手部特写             约 40 分钟
② 上顶部（上去一次）  → 第 3 条搭站 + 第 6 条拆站      约 50 分钟
③ 顶绳爬一次（POV）   → 第 1 条全集流程               约 40 分钟
④ 挂片处 / 挂片下方   → 第 2 条部分 + 第 5 条         约 30 分钟
⑤（如果有人在）       → 第 2 条情景 + 第 5 条保护员    约 40 分钟
```

**总计约 3–4 小时**（不含爬山和休息）。

# 四、⭐ 一次拍摄的清单（打印出来划勾）

## 出门前

```
□ 手机 ×2（一台主拍，一台拍 B 机位）
□ 三脚架 ×2（一个拍你，一个拍侧面）
□ 运动相机 + 挂胸配件（充满电，带备用电池）
□ 手机夹 / 手机绳
□ 整套装备：头盔、安全带、鞋、主绳、主锁、保护器、快挂 ×几个、扁带
□ 水 + 吃的（3–4 小时）
□ 充电宝
```

## 拍摄顺序（照这个走）

```
① 到岩场后先别急，找好背景和光线
② 位置 A（崖底）：A1 → A2 → A3 → A4 → A5 → A6 → A7 → A8 → A9 → A10
③ 位置 B（上顶部）：B1（先在下面仰拍）→ 上去 → B2 → B3 → B4 → B5 → B6
④ 位置 C（顶绳）：C4 先开录 → C1 → C2 → C3 → C5
⑤ 位置 D（挂片处）：D1 → D2 → D3 → D4
⑥ 位置 E（有人就拍）：E1 → E2 → E3 → E4 → E5 → E6 → E7
```

## 每个镜头开拍前问自己三句

```
1. 这是给哪一条用的？（说不出来就是废镜头）
2. 光线够吗？（看不清就重拍）
```

# 八、几条拍摄纪律

1. **安全第一。** 上顶部一定要有保护，不为拍镜头冒险
2. **一次只改一个变量。** 机位架好就别动，光线一致
3. **同一套衣服。** 一次拍摄的全部素材，衣服别换（不然剪起来像两天的）
4. **拍够 3 倍时长。** 2:20 的片子，素材至少 7 分钟。**宁可多拍**
5. **不确定就重拍。** 同一个镜头拍两遍，成本很低
6. **环境音单独录 1 分钟。** 站着别动，就录风声、金属声、绳子摩擦声
