# 一、这是什么

**14 条视频 · 四阶递进 · 从"第一次去野攀"到"多段结组"**

## 定位

> **记录一个攀岩者在阳朔的学习过程，顺便把我知道的东西讲清楚。**

**不是课程大纲，是成长记录。**

区别在哪：
- 课程大纲 = 自上而下（先有课，再有视频）→ 观众觉得在被推销
- 成长记录 = 自下而上（视频是过程，课自然长出来）→ 观众愿意跟着

> 🔑 **观众不关心里程碑，观众关心"这个人跟我像不像"。**
> 你越像"一个正在学的人"，越多人愿意跟着。

# 三、三条核心原则

## ① 前 10 条**完全不提课程**

```
不是课程不好，是顺序倒了：

第一步：让人认识你（人格）
第二步：让人相信你（专业）
第三步：人才会问「你有没有课」   ← 现在跳过了前两步
```

**"课程衔接话术"全部换成"下期悬念"**：
```
❌ 「我把野攀从入门到先锋整理成了系统课程」
✅ 「下一条讲新手最容易犯的礼节问题——我第一次去的时候也犯过」
```

效果一样（留人 + 建立期待），但**没有人会觉得被推销**。

> 真正想学的人会翻你主页 / 评论区问你 / 私信你 —— **那才是提课程的时机**，
> 而且那时候是**他问、你答**，不是**你推、他躲**。

## ② 每条至少一句"我"

```
「我第一次去的时候也犯过」      ← 礼节条
「我当时牛尾挂反了」            ← 保护站条
「我手被卡住的那一次」          ← 入挂条
「两次冲坠之后我才搞懂」        ← 绕脚条
「我跟搭档吵过的那次」          ← 口令条
```

**为什么重要**：你抖音现在涨粉转化只有 **0.18%**——观众看完就走，
因为**没有任何理由想知道你是谁**。这批内容如果能提到 **0.5%**，粉丝能从 205 涨到 400+。

## ③ 机位配比：第三人称 60% / POV 30% / 特写 10%

| 机位 | 拍什么 | 观众获得 |
|---|---|---|
| **第三人称**（手机 + 三脚架） | 你出镜讲、演示、情绪 | "看你" ← **主力，占 60%** |
| **POV**（运动相机挂胸） | 攀爬、下降、手上动作 | "代入" |
| **手部特写**（手持 60fps） | 关键动作 3 秒 | "看清" |

> ⚠️ **POV 用得越多，人格越弱。** 纯 POV 观众只看到一双手，看 10 条会腻。
> **第 2 条（礼节）全程第三人称**；**第 8、10 条（冲坠）全程第三人称**——讲情绪要看到你的脸。

# 四、排期

## 发布时间

```
首发：2026-10-13（周二）19:30
周期：4 天 1 条
```

**为什么是 10-13**：
- 10-05 装备系列收官 → 需要 8 天缓冲（拍 + 剪 + 插一条过渡）
- 10-12 是周一（一周里最差的发布日）
- **10-13 周二** ← 你历史高播放作品里，快挂 16,000 就是周二发的

**为什么 4 天 1 条**：
```
图文：写脚本 1 天 + 做图 1 天 = 2 天
视频：写脚本 + 拍摄（要爬山）+ 剪辑 = 5–7 天
```
**视频的周期天然比图文长。硬追 2 天一条会崩。**
而且——**一条爆款 > 十条平庸**（快挂 16,000 单独贡献了那几天大部分涨粉）。

# 五、拍摄计划：**批量拍摄，分散发布**

## 核心思路：别按"条"拍，按"位置"拍

同个位置的所有镜头一次拍完，省掉来回折腾。

```
① 崖底（不爬）        → 出镜讲 + 手部特写        约 40 分钟
② 上顶部（上去一次）  → 第 3 条搭站 + 第 6 条拆站   约 50 分钟
③ 顶绳爬一次（POV）   → 第 1 条全集流程           约 40 分钟
④ 挂片处             → 第 2 条部分 + 第 5 条       约 30 分钟
⑤（有人在）           → 第 2 条情景 + 第 5 条保护员  约 40 分钟
```

**总计约 3–4 小时**（不含爬山和休息）。

## 一次爬山能拍几条

```
如果约得到 1 个岩友：
  ✅ 第 1、2、3、4、5、6 条  →  全部拍完

如果只有你一个人：
  ✅ 第 1、3、4、6 条        →  拍完（4 条）
  ⏸ 第 2、5 条               →  等有人的时候再拍
```

> ⚠️ **不要为了拍而找人演戏** —— 观众看得出来。等有真实场景再拍。

## 一天的拍摄时间表

| 时间 | 干什么 |
|---|---|
| 8:00–9:00 | 到岩场、选线、架设备 |
| 9:00–10:00 | 位置 A（崖底，光线最柔） |
| 10:00–11:00 | 位置 B（上顶部，搭站 + 拆站） |
| 11:00–12:30 | 位置 C（顶绳 + POV） |
| **12:30–13:30** | **吃饭 + 回看上午拍的** ⭐ |
| 13:30–14:30 | 位置 D（挂片处） |
| 14:30–15:30 | 位置 E（有人就拍）+ 补漏 |
| 15:30–16:00 | 收工、清点素材 |

> ⚠️ **12:30 那 1 小时很关键** —— 一定要回看上午拍的。
> 发现哪个不行，下午还能补。**回家才发现就晚了。**

## 拍摄纪律（6 条）

```
1. 安全第一。上顶部一定要有保护，不为拍镜头冒险
2. 一次只改一个变量。机位架好就别动，光线一致
3. 同一套衣服。一次拍摄的全部素材，衣服别换
4. 拍够 3 倍时长。2:20 的片子，素材至少 7 分钟
5. 不确定就重拍。同一个镜头拍两遍，成本很低
6. 环境音单独录 1 分钟（风声、金属声、绳子摩擦声）
```
