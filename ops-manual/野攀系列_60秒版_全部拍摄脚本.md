# 野攀系列 · 60 秒版拍摄脚本（第 1–6 条）

> **硬约束：每条不超过 60 秒**
> 2026-10-05 重写（替代此前的 2:00–2:20 版本）
> 第一批一次爬山拍完

---

## ⚠️ 60 秒的规则（和长版完全不同）

| | 长版（2:20） | **60 秒版** |
|---|---|---|
| 一条讲几个点 | 3–5 个 | **只讲 1 个** |
| 开场 | 可以慢慢铺 | **3 秒内必须给钩子** |
| "感受"段 | 有 30 秒 | **砍掉，或压成最后一句** |
| 剪辑 | 平滑过渡 | **硬切，不留过渡** |
| 字幕 | 完整句子 | **关键词（4–8 字）** |

## 统一骨架（每条都照这个）

```
0:00–0:03   钩子      最强画面 或 最强结论。不要"大家好"
0:03–0:10   建立预期   一句话说清"这条讲什么"
0:10–0:50   主体       ⭐ 只讲 1 个点（最多 2 个）
0:50–0:58   收尾       一句总结 或 一句悬念
0:58–1:00   结束
```

## 统一机位（不变）

```
第三人称（三脚架）  60%   ← 主力
POV（运动相机挂胸） 30%   ← 只在"爬"的时候
手部特写（手持）    10%   ← 每个关键动作 3 秒
```

# 🎬 第 1 条｜第一次去野攀（58 秒）

**一句话主线**：站 → 穿 → 爬 → 落地，一口气走完。

| 时间 | 拍什么 | 机位 | 说什么 |
|---|---|---|---|
| 0:00–0:05 | 站着抬头看岩壁（8 秒素材剪成 5 秒） | 三脚架·仰拍 | **不说话** |
| 0:05–0:12 | 同上，转头看镜头 | 三脚架 | 「第一次来的人……/ 都会先站在这儿看一会儿。」 |
| 0:12–0:22 | **快剪 3 个动作**：戴头盔扣扣子 / 安全带回穿 / 打结捋绳尾 | 手持特写 | 「穿的跟岩馆差不多。/ 只有一样不一样——**绳子是系在你身上的**。」 |
| 0:22–0:50 | ⭐ **POV 一条拍完**：爬 → 拍顶链 → 下降 | POV | 爬时只说动作词（"这个大点""休息一下"）；**下降段全程不说话** |
| 0:50–0:58 | 落地，坐下或站着 | 三脚架·半身 | 「第一次爬野外，感觉不是难。/ 是**下面没人替你负责**。」 |
| — | 结尾 | | 「下一条：野攀的 5 个礼节，我也犯过。」 |

**⚠️ 三个必须**
1. 前 5 秒**只有画面，没有说话**
2. 「绳子是系在你身上的」后**停 1.5 秒**
3. 下降段**一句话都不说**（留风声和绳子声）

# 🎬 第 2 条｜5 个礼节（59 秒）

**一句话主线**：5 个规矩，每个"错→对"两秒对比。

| 时间 | 内容 | 说什么 |
|---|---|---|
| 0:00–0:06 | 你站着，背景岩壁 | 「野攀有些规矩，没人会明着告诉你。/ 但做错了，**旁边的人不会说，会记住**。」 |
| 0:06–0:16 | ① **排队**：抽别人绳子（错）→ 站着等（对） | 「别人爬的时候，**别动他的绳子**。」 |
| 0:16–0:26 | ② **装备**：直接翻包（错）→ 先问再动（对） | 「别人的装备，**问一句再用**。」 |
| 0:26–0:36 | ③ **挂片**：踩挂片（错）→ 踩岩壁（对） | 「挂片不是给你踩的，**踩松了下个人不安全**。」 |
| 0:36–0:46 | ④ **拍照**：直接拍（错）→ 喊一声再拍（对） | 「拍别人之前，**先说一声**。」 |
| 0:46–0:59 | ⑤ ⭐ **你把自己的包放在岩壁正下方**（真实，不演戏） | 「这个是我犯过的。/ 有人跟我说——**上面掉东西，第一个砸你的包**。/ 从那以后我再没放过。」 |

**⚠️ 三个必须**
1. **全程第三人称**，不要 POV
2. 每个礼节**字幕标【错】【对】**，不要用旁白解释
3. 礼节⑤ **必须是真的把包放在那儿**，不要表演"错误示范"

# 🎬 第 3 条｜我搭过最烂的保护站（58 秒）

**一句话主线**：搭一个只有单锁的站 → 说三个错 → 现在怎么做。

| 时间 | 拍什么 | 机位 | 说什么 |
|---|---|---|---|
| 0:00–0:08 | 仰拍顶部挂片（8 秒素材剪 5 秒 + 3 秒字幕卡） | 崖底仰拍 | 「顶上那两个挂片，我第一次搭站就搭这儿。/ 当时觉得没问题。」 |
| 0:08–0:30 | **快剪搭站**：挂扁带 → 交汇 → 扣**一个**主锁 → 停 | 侧面全景 + 手部特写 | 「两条扁带拉过来，交汇，中间**扣一个主锁**。」【停 1.5 秒】 |
| 0:30–0:52 | 坐着/站着讲三个错（字幕打【错 1】【错 2】【错 3】） | 侧面·能拍到你和保护站 | 「① 扁带**夹角太大**，挂片受力翻倍<br>② 中间**只有一个锁**，坏了整条断<br>③ 扁带**拧着**受力，强度掉一半」 |
| 0:52–0:58 | 对着镜头 | 同上 | 「现在我：**夹角收小、两个锁、扁带顺直**。」 |
| — | 结尾 | | 「下一条：保护站拆除。」 |

**⚠️ 安全红线**
```
上顶部必须有保护 → 重演只做"错误的是做法"，不做危险动作
风大 / 湿滑 → 改期
```

# 🎬 第 4 条｜为什么只用一种结（55 秒）

**一句话主线**：两个结各打一遍 → 有一次绳尾没收 → 从此改用一个。

| 时间 | 拍什么 | 机位 | 说什么 |
|---|---|---|---|
| 0:00–0:06 | 手里拢一下绳 | 三脚架·半身 | 「我一开始用布林结，后来只用八字结。/ **不是因为哪个更牢——是因为一件事。**」 |
| 0:06–0:30 | **两个结各打一遍**（快剪，各 10 秒 + 2 秒定格） | 手持·60fps | **不说话**（后期打字幕：布林结 / 八字结） |
| 0:30–0:50 | 坐着讲 | 三脚架·半身 | 「有一次天快黑，收绳的时候——**布林结的绳尾没收进去。**/ 它不一定出事，但那天我盯着看了很久。」 |
| 0:50–0:55 | 同上 | | 「所以我不比谁更牢，/ **我比谁打错的概率低**。八字结打错了一眼看得出来。」 |

**⚠️ 三个必须**
1. 两个结的**手速一致**（不公平会显得假）
2. 「**不是八字结更牢，是打错概率更低**」是全片金句，必须留
3. 必须是**真事** —— 不是你的经历就换成真的那次

# 🎬 第 5 条｜保护最容易犯的错（60 秒）

| 0:05–0:17 | ① **绳太松**（错）→ 微绷（对） | 「绳太松——上面的人要先吃一段松绳才受力。」 |
| 0:17–0:29 | ② **站太远/太近**（错）→ 1-1.5 米（对） | 「站太远撞墙；站太近，**掉石头第一个砸你**。」 |
| 0:29–0:41 | ③ **低头看手机、绳子松了不管**（错）→ 收手机看人（对） | 「上面的人**不会提前告诉你要掉了**。/ 你低头那两秒，就是他掉的那两秒。」 |
| 0:41–0:50 | ④ **制动手位置不对**（错）→ 永远在制动端（对） | 「制动手**永远在制动端**，练成习惯。」 |
| 0:50–1:00 | 对着镜头 | 「这 4 个我犯过两个——**站位太近**，还有**低头看手机**。/ 不是天生会的，**是这些事把我教会的**。」 |

**⚠️ 必须**
1. **同一个机位**拍 4 个错（不要换机位）

3. 结尾那句「**不是天生会的，是这些事把我教会的**」必须留

**🔴 安全**：错误示范只做"静态的"，**不做真实坠落演示**。
