# 互动引导规范（CTA 三件套）

> **建立于** 2026-09-18
> **起因**：第 0 集「装备导览」发布后 **收藏 0 / 分享 0**。
> 用户指出：**"没有一个好的引导的话，他愿意去点赞收藏"** —— 核对文案，确实**只有评论引导，没有收藏和分享引导**。
> **用户的判断（以她为准）**：**点赞 + 收藏 + 分享 才是最重要的指标**，不是划走率/完读率。

---

## 一、指标优先级（修正）

| 层级 | 指标 | 说明 |
|---|---|---|
| **① 结果指标** | **点赞 / 收藏 / 分享**（+ 关注） | **这才是推荐权重的核心**，也是内容"有用"的直接证据 |
| ② 过程指标 | 完读率 / 平均浏览图数 | 说明内容本身好不好，**但不能代替结果** |
| ③ 诊断指标 | 划走率 | **只看"曝光→点击"的转化**，不要拿它判断内容好坏 |

> ⚠️ **教训**：第 0 集我盯着「划走率 71.43%」下结论，方向错了。
> 真实情况是：**完读率 80%（内容没问题）+ 划走率高（进去的人少）** →
> 问题在封面/标题，不在内容。**两个指标要一起读。**

---

## 二、铁律：每条内容必须有 CTA 三件套

**收藏、分享、评论 —— 三个动作，各给一句，功能不重叠。**

```
① 收藏句    「买之前把这条收藏一下，照着对」
② 分享句    「身边正要买 XX 的朋友，转给他，能少踩一个坑」
③ 评论句    「你现在用的是 ATC 还是龟龟？评论区说说」
④ （可选）关注句 —— 只在内容确实成体系时用，别每条都求关注
```

### 三句话的设计要点

| 动作 | 为什么难 | 怎么写 |
|---|---|---|
| **收藏** | 用户要判断"以后还用得上" | 指向**决策场景**：「买之前」「下次 X 的时候」 |
| **分享** | 最难。用户怕像在帮人打广告 | 给一个**利他理由**：「转给他能少踩一个坑」「朋友问起直接甩这条」 |
| **评论** | 最容易，但问得空就没用 | 问一个**用户本来就想说的事**，别问"你觉得呢" |

> ❌ 不要写：「喜欢的话点个赞」「记得三连」—— 那是求，不是给理由。
> ✅ 要写：**给用户一个"这么做对我有好处"的理由。**

---

## 三、引导放在哪

| 位置 | 作用 | 备注 |
|---|---|---|
| **文案结尾** ⭐ | 最主要。图文/视频都看得到 | **必须写**，别省 |
| **最后一页图** | 图文特有，收藏钩子最佳位 | 第 3 集结论页已有「买之前把这页存下来」 |
| **作者评论** | 已发布作品的补救位 | 作者评论权重高，不用置顶也在前排 |
| **评论区回复** | 每次回复都是一次互动信号 | 尤其要回「这个我用得上」这类评论 |

---

## 四、标签同步（别忘）

每条内容的交付物必须包含：

```
□ 标题（带搜索词 + 钩子）
□ 正文（含 CTA 三件套）
□ 标签（大词 + 精准词 + 人群词，5 个）
□ 封面（抖音：钩子型 / 小红书：纯照片 0 文字）
```

---

## 五、自查清单（发布前过一遍）

```
□ 收藏句写了吗？
□ 分享句写了吗？给了"利他理由"吗？
□ 评论句写了吗？问的是用户本来就想说的事吗？
□ 三句有没有功能重叠？（别三句都在求评论）
□ 图上有没有一个"存这一页"的视觉钩子？
□ 标签 5 个齐了吗？
```
