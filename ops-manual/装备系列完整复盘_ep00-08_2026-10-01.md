# 二、⭐ 三条核心发现

## 发现 1：**划走率在装备系列内几乎失灵了**（推翻我之前的说法）

```
划走 39.09% →  4,654  (ep06 自保)
划走 42.69% → 16,000  (ep04 快挂)   ← 播放第 1
划走 44.52% →  4,110  (ep05 扁带)
划走 45.53% →  2,761  (ep07 头盔)
划走 46.86% →  3,528  (ep03 保护器)
划走 48.25% →  8,989  (ep01 主锁)   ← 播放第 2
划走 51.30% →  3,613  (ep02 主绳)
划走 56.61% →  1,512  (ep00 第0集)  ← 播放最低

ρ(播放, 划走率) = −0.246
```

| 数据范围 | ρ(播放,划走率) |
|---|---:|
| 全账号 19 条（**含视频+图文**） | **−0.501** |
| **装备系列 9 条（全是图文）** | **−0.246** |

### 🔧 修正结论

> **划走率在「跨形态比较」时有效（视频 vs 图文），在「同一形态内」区分度很弱。**

原因：装备系列全是图文，划走率全挤在 **39–57%** 这个窄区间里，**区分度不够**。
而全账号那批含 5–8 月的视频（划走率 37%–62%），跨度大，所以相关性强。

⚠️ **这也意味着我 09-23 那条修正（"OBS-004 维持有效"）需要再修正** ——
**OBS-004 应该限定条件：只在跨形态比较时成立。**

```
0.26%  自保     (4,654 播 → 12 粉)

0.13%  第0集    (1,512 播 → 2 粉)
```

**全在 0.13%–0.26% 之间，差不到 2 倍。**

### 📌 结论

> **涨粉 ≈ 播放 × 0.2%。** 内容好坏几乎不影响这个系数。

**这意味着：**
- ❌ 想涨粉，**不是"把内容做得更好"**，而是**"把播放做大"**
- ❌ 也别指望靠"内容质量"提升涨粉率
- ✅ 唯一能改这个系数的，是**让人想认识你**（人格）——而装备系列里没有任何一条在做这件事

**数字验证**：你 9 月 15 天发 9 条，总播放约 4.6 万 × 0.2% ≈ **92 粉**。
实际从 148 涨到约 205 是 **+57**（同期还有其他内容）——**量级吻合。**

# 三、预测精度分析

```
−70%  −41%  −34%  −21%  −8%  +0%  +33%  +191%
平均绝对误差 52.8%   中位偏差 −21.0%
```

**分布极不均匀**：4 条低估、4 条高估，**没有系统性偏差，但单条误差巨大。**

| 类型 | 案例 | 问题 |
|---|---|---|
| **大幅高估** | ep00 (−70%)、ep03 (−41%)、ep08 (待定) | |
| **大幅低估** | ep04 (+191%) | |
| **准** | ep02 (+0%)、ep01 (−8%) | |

### 两个极端案例的根因

**ep00（−70%）**：只发了 **2 张图**（设计是 8 张）。
→ **rubric 里没有"内容体量"维度。** 评分时 7 维全在评"内容好不好"，**没有一维在评"够不够"**。

**ep04（+191%）**：快挂是**唯一做对了"选题热度"的**——
它是唯一 3:4 画幅、唯一标题完全命中 OBS-016、且"可以买好几把"的高频装备。

### 🎯 结论

> **×0.85 这个全局校准系数应该取消。**
> 它修不了 52.8% 的平均误差，只会掩盖个案。

# 四、⭐ 高组 vs 低组：差在哪

```
高组：ep04 16,000 / ep01 8,989 / ep06 4,654
低组：ep08 1,362 / ep00 1,512 / ep07 2,761
```

| 指标 | 高组均值 | 低组均值 | 差异 |
|---|---:|---:|---|
| 划走率 | **43.34%** | 47.63% | 低组高 4.3pp |
| 收藏率 | **0.57%** | 0.36% | 高组高 58% |
| 平均浏览图 | 2.80 | 2.67 | 几乎无差 |

**划走率和收藏率**在两个组有区分，但**幅度不大**（ρ 只有 −0.25 / +0.16）。

### 目前最能解释分群的假说

| 假说 | 支持度 |
|---|---|
| **画幅 3:4 > 9:16** | ⚠️ 快挂（3:4）16,000 vs 保护器（9:16）3,528。但主锁（9:16）也 8,989 → **假说被削弱** |
| **选题热度**（人人要买 vs 买一次用很久） | ⭐ **目前最能解释**：快挂（可买多把）16,000 / 主锁（入门第一件）8,989 vs 主绳（买一条用三年）3,613 / 保护器（一买一个）3,528 |
| **结论页可存档性** | ⭐ 解释**收藏率**有效（主绳 1.16% 第 1），**不解释播放** |
| **内容体量** | ⭐ 解释 ep00（2 张 → 1,512） |

**→ 目前最好的假说：**
> **播放由「选题热度」驱动，收藏由「结论页可存档性」驱动，两者独立。**
