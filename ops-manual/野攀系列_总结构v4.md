# 一、4 门课 ↔ 4 季 ↔ 4 个抖音合集

```
课程              抖音合集（= 课程名）    条数    脚本类型        时长
──────────────────────────────────────────────────────────────────────
① 体验课    →    《野攀体验》            2      开放式         10–35 秒
② 顶绳课    →    《顶绳系统》            6      半结构         45–60 秒
③ 先锋课    →    《先锋进阶》            8      执行型         45–60 秒
④ 结组课    →    《多段结组》            9      执行型+参数    45–60 秒
                                                  ─────
                                                  25 条
```

> ⚠️ **60 秒是上限，不是目标。** 体验季（抽象型）越短越好，10–15 秒最优。

## ⭐ 为什么用 4 个独立合集（不是 1 个总合集）

**抖音合集不能嵌套** —— 一个作品只能进 1 个合集，合集不能再套合集。

| 理由 | 说明 |
|---|---|
| 1 | **合集名 = 课程名** → 观众看到《顶绳系统》就懂"这是一门课" |
| 2 | **合集内相关度高** → 播放页会引导看下一条，连看率更高 |
| 3 | **体系感更强** → 4 个阶段一眼看懂；1 个大合集反而像"一堆视频" |

**体验季只有 2 条也建合集** —— 合集入口会出现在播放页，是拉连看最省力的东西。
**主页置顶这 2 条**（抖音可置顶 3 条），与合集不冲突。

# 一·五、⭐ IP 四层（本体系的主线）

| 季 | 观众记住的「你」 | 靠什么建立 |
|---|---|---|
| ① 体验 | **「这人好玩」** | 抽象 + 自嘲 |
| ② 顶绳 | **「这人靠谱」** | 细节 + 较真 |
| ③ 先锋 | **「这人也会怕，但他还爬」** | 恐惧 + 真实 |
| ④ 结组 | **「这人可以托付」** | 判断力 |

```
好玩  →  靠谱  →  共情  →  信任
                            ↓
                        信任 = 付费的前提
```

**"立 IP"不是到先锋季才开始 —— 第一季就在做，只是每季露出的侧面不同。**

## 🔴 红线

```
✅ 可以抽象：你的反应 / 你的情绪 / 你的失败
❌ 不能抽象：安全操作 / 装备检查 / 保护流程
```
> **情绪怎么抽象怎么来，动作必须一板一眼。**

# 二、⭐ 脚本类型（四季不同，这是关键）

| 季 | 类型 | 给什么 | 不给什么 |
|---|---|---|---|
| ① 体验 | **开放式** | 拍什么 + 什么情绪 + 3-5 个关键词 | ❌ 不写台词 |
| ② 顶绳 | **半结构** | 骨架 + 3-4 句关键句 | ⚠️ 不逐字 |
| ③ 先锋 | **执行型** | 完整口播稿（标停顿、重音） | — |
| ④ 结组 | **执行型 + 参数** | 口播稿 + 技术参数表 | — |

**逻辑**：
```
体验季的任务 = 拉人     → 靠"感觉"     → 写死了就没感觉了
结组季的任务 = 交付     → 靠"精确"     → 必须逐字
```

> ⚠️ **v1/v2/v3 的错就在这** —— 用同一套详细脚本套四季。
> 体验季被我写成了教学片（"安全是人给的"这种结论句），**那不该是体验季讲的话**。

# 三、四季细目（26 条）

## ① 《野攀体验》— 2 条 ｜ 开放式脚本 ｜ 10–35 秒

| # | 标题方向 | 拍什么 | 情绪 |
|---|---|---|---|
| **E1** | 爬完，我只说了一个字 | 抬头 → 爬快剪(2-3 动作) → 到顶 → 下来 → **说一个字** → 特效 | 抽象 / 反差 / 自嘲 |
| **E2** | 我在岩场干过的 3 件蠢事 | ①保护员前方走过 ②挂绳没问就上 ③留了个镁粉块（**全部用"我"**） | 自嘲 |

**E1 的写法**：
```
✅ 给：卡点在哪、说哪个字（给 3 个候选让她选）、特效怎么收
✅ 给：结尾一行小字幕（专业底座）「5.7，阳朔最简单的线之一」
❌ 不给：台词、结论句
时长：10–15 秒（越短越好）
```

**E1 选字的逻辑 = 反差**：
| 观众预期 | 给 | 效果 |
|---|---|---|
| 好难/好累 | 「爽」 | 反差 |
| 好怕 | 「饭」 | 抽象 |
| 爬上去了不起 | 「就这？」 | 自嘲 |

**E2 的写法**：
```
把「礼节」改成「我的蠢事」——同样传递信息，但：
  立场从"你别这样做"（说教）→ "我干了这事"（自嘲）
  情绪 ✅ 符合 Open 的性格
  爆率 ✅ 更高
时长：25–35 秒
```

> ⭐ 体验季这 2 条**不是"预热"，是 IP 的地基**（见「IP 四层」）。

```

```
