# 一、4 门课 ↔ 4 季 ↔ 4 个抖音合集

```
课程              抖音合集（= 课程名）    条数    脚本类型
──────────────────────────────────────────────────────────────
① 体验课    →    《野攀体验》            3      开放式（不写台词）
② 顶绳课    →    《顶绳系统》            6      半结构（骨架 + 关键句）
③ 先锋课    →    《先锋进阶》            8      执行型（完整口播稿）
④ 结组课    →    《多段结组》            9      执行型 + 参数表
                                                  ─────
                                                  26 条
```

## ⭐ 为什么用 4 个独立合集（不是 1 个总合集）

**抖音合集不能嵌套** —— 一个作品只能进 1 个合集，合集不能再套合集。

| 理由 | 说明 |
|---|---|
| 1 | **合集名 = 课程名** → 观众看到《顶绳系统》就懂"这是一门课" |
| 2 | **合集内相关度高** → 播放页会引导看下一条，连看率更高 |
| 3 | **体系感更强** → 4 个阶段一眼看懂；1 个大合集反而像"一堆视频" |

**代价**：初期每个合集条数少（体验 2 条、顶绳 2 条）。只是"还没拍完"，不是问题。

# 二、⭐ 脚本类型（四季不同，这是关键）

| 季 | 类型 | 给什么 | 不给什么 |
|---|---|---|---|
| ① 体验 | **开放式** | 拍什么 + 什么情绪 + 3-5 个关键词 | ❌ 不写台词 |
| ② 顶绳 | **半结构** | 骨架 + 3-4 句关键句 | ⚠️ 不逐字 |
| ③ 先锋 | **执行型** | 完整口播稿（标停顿、重音） | — |
| ④ 结组 | **执行型 + 参数** | 口播稿 + 技术参数表 | — |

**逻辑**：
```
体验季的任务 = 拉人     → 靠"感觉"     → 写死了就没感觉了
结组季的任务 = 交付     → 靠"精确"     → 必须逐字
```

> ⚠️ **v1/v2/v3 的错就在这** —— 用同一套详细脚本套四季。
> 体验季被我写成了教学片（"安全是人给的"这种结论句），**那不该是体验季讲的话**。

# 三、四季细目（26 条）

## ① 《野攀体验》— 3 条 ｜ 开放式脚本

| # | 标题方向 | 拍什么 | 情绪 |
|---|---|---|---|
| **E1** | 第一次去野攀 | ⭐ **爬一条非常简单的线**，从出发到落地走一遍 | open / 兴奋 / 陌生 |
| **E2** | 岩场礼节：没人当面说你的 3 件事 | 保护员前方 · 挂绳询问 · 垃圾 | 认真的（唯一"实"的一条） |
| **E3** | 为什么我还在爬 | 纯画面 + 一点独白 | 收尾 / 沉淀 |

**E1 的写法**：
```
✅ 给：地点、时间、要拍哪几个瞬间（抬头看 / 穿装备 / 上墙 / 到顶 / 下来坐下）
✅ 给：3 个关键词（陌生、手忙脚乱、下来还想再来一次）
❌ 不给：台词。让她自己在现场说话，说错了也没关系
❌ 不给：结论句
```

**E2 是这一季唯一"半结构"的**（礼节是知识，必须有骨架）。

## ② 《顶绳系统》— 6 条 ｜ 半结构脚本

| # | 标题 | 关键句（必须有） |
|---|---|---|
| **T1** | 建站：在地面就能讲清楚 | 「冗余在前面那一层做」 |
| **T2** | 布林结：除了不好检查，全是优点 | 「把检查做成习惯，它就没有缺点了」 |
| **T3** | 给人做保护，最要命的就是那两秒 | 「上面的人不会提前告诉你要掉了」 |
| **T4** | 拆站，我第一次拆的时候手是抖的 | 「先挂自己，最后解自己」 |
| **T5** | 顶绳保护的站位和绳松紧 | 「绳太松 = 白掉一段」 |
| **T6** | 顶绳一天，从头到尾走一遍 | 「这一季的总结」 |

## ③ 《先锋进阶》— 8 条 ｜ 完整口播稿

| # | 标题 |
|---|---|
| **P1** | 先锋入挂：我手被卡住的那一次 |
| **P2** | 绕脚：两次冲坠之后我才搞懂 |
| **P3** | 先锋口令：我跟搭档吵过的那次 |
| **P4** | 第一次冲坠，我脑子里在想什么 |
| **P5** | 先锋收绳，我收错过一次 |
| **P6** | 先锋保护，和顶绳保护差在哪 |
| **P7** | 我为什么到现在还怕先锋 |
| **P8** | 先锋我踩过的 5 个坑 |

## ④ 《多段结组》— 9 条 ｜ 口播稿 + 参数表

| # | 标题 | 技术点 |
|---|---|---|
| **M1** | 结组和单段，到底差在哪 | 认知 |
| **M2** | 结组装备：半绳、双绳、抓结 | 装备 |
| **M3** | 结组建站：多重锚点怎么均衡 | 建站 |
| **M4** | 上方保护 / 下方保护 / 跟攀保护 | ⭐ 三种不一样 |
| **M5** | 跟攀收绳，我收错过一次 | 操作 |
| **M6** | 交替领攀怎么分工 | 协作 |
| **M7** | 过站：到站之后的第一步 | 操作 |
| **M8** | 撤退：什么时候该放弃 | ⭐ 判断 |
| **M9** | 出发前要问的 5 个问题 | 规划 |

# 五、课程连接（不喊广告）

**做法 1｜合集名 = 课程名**
```
抖音合集《顶绳系统》    课程《顶绳课》
```

**做法 2｜每条结尾说"位置"，不说"卖点"**
```
「这是《顶绳系统》的第 2 条。/
 这一季 6 条，讲完你就能自己搭一个顶绳站。」
```
← 说位置和承诺，不说价格和报名

**做法 3｜简介放路线图**
```
野攀从 0 到结组，4 季：
① 体验 ② 顶绳 ③ 先锋 ④ 结组
新手问题评论区问，我看到就回
```

**做法 4｜等他们问**
有人问「你教不教」的时候，才是时机。
